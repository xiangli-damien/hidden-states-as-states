## B. 通用约定

1. **模型与生成设置**与当前一轮完全相同（Qwen2-7B-Instruct、chat template、dtype、贪心、`max_new_tokens=2048`）。配置里引用当前一轮配置文件的哈希。
2. **干预位置**是当前一轮所用的 block 14 残差输出。d、ŝ、τ、v_T、局部基等所有量都必须在这个位置计算。开跑前做一次断言：teacher forcing 在钩子处取到的激活，与 response 级 map 所用的"第 14 层"表示逐元素一致（相对误差 < 1e-3）。层号错一位，所有结果都会失效。
3. **生成位置**指 prompt 之后的全部位置，包括补上去的强制作答字符串和答案 token。第一个生成 token 由 prompt 最后一个位置预测，因此不受干预，这与当前一轮一致。
4. **回答均值**只对生成 token 求平均（论文 §3.1 的定义）。0 个 token 的回答记为缺失并计数。
5. **句子切分**用与 §5.2 相同的函数，并记录函数名。需要 token 偏移时，用分词器的 offset mapping 把句子起点映射到 token 下标。
6. **评分**：主终点一律用冻结的原自动评分；统一重评分和 AI 阅读只作敏感性分析。"boxed" 沿用当前一轮报告中"完整非空 boxed"的定义。
7. **数值**：投影和 log 概率一律在 float32 里计算，log 取自然对数。
8. **批处理**：padding 位置既不施加干预，也不计入任何指标。
9. **拼接**：需要在原回答后接字符串时，用原回答的 token 序列，后面接单独分词的字符串（`tok(FORCE)`、`tok(答案 + "}")`），不要把整段文本重新分词。

## C. 第 1 步：重新编码当前一轮的输出（不生成新回答）

**输入**：当前一轮跑完后，三组（zero、hss、random）在 55 道目标题和 100 道正常题上的输出；以及这些题的历史回答。

**做法**

1. 每条回答做一次无钩子的 teacher forcing，取各层隐藏状态，计算：
   - 回答均值 m_ℓ(r)，所有层；
   - 每个句子边界处的前缀均值（所有层，fp16 存储）。这只为 3B 准备，现在一起算，省掉第二次前向。
2. 用冻结的生成均值 map 做各层分配（与论文相同的分配函数），得到全局状态 ID。
3. sink = 第 14 层（钩子层）的 sink 全局 ID。L_late = 冻结 map 中这个全局 ID 仍然存在的最深一层，开跑前从 map 本身确定并写入配置。

**指标**（全部是描述性的，不影响后面的任何决策）

- **a. 离开率**：只看 zero 组回答仍在 sink 里的目标题（记为 Q0），统计 HSS 组、随机组各有多少题的回答不在 sink 里。两组配对比较用 `paired_binary_summary`（McNemar 精确检验）。
- **b. 落点**：离开者落到哪个状态；该状态的主导题型（来自训练集的状态标注）是否等于这道题的题型。
- **c. 沿 d 的位移**：p_arm(q) = (m_14(r_arm) − m_14(r_zero)) · d̂_run，其中 d_run 是当前一轮实际用的方向。HSS 对随机做 Wilcoxon 符号秩检验。在 L_late 上，用在固定回答集合上算出的 d_{L_late} 再做一次。
- **d. 强制作答**：对每条没有完整非空 boxed 的回答，上下文 = prompt ⊕ 原回答 token ⊕ tok(FORCE)，贪心补全最多 40 个 token，用 `extract_braced` 取出答案，再用冻结评分器判对错。每组报告：未 boxed 数、强制后答对数，以及"已答对或强制后答对"的总数。
- **e. 复现性**：zero 组文本与历史文本逐字相同的比例，以及第一个不同 token 的位置。正常题低于 90% 时在报告中标注，说明当前管线与历史生成不一致。
- **f. 说明**：当前一轮的随机组只有一个随机方向，所以关于它的结论只能写成"没有胜过一个等范数随机扰动"。

**输出**：`step1_reencode.parquet`（每条回答一行）、`step1_prefix_states.npz`、`step1_summary.json`。

## D. 第 2 步：似然筛选（主实验；只用训练集；不生成）

### D1. 数据

- **训练集**：拟合 response 级 map 时用的训练划分，与当前一轮计算 d 用的数据相同。
- **S**：训练集中第 14 层落在 sink（簇 8）的回答，共 197 条。**N**：其余回答，共 2,814 条。
- **分层对半**：用 `stratified_half_split`（种子 20260925）。S 按题型分层，得到 S_A、S_B；N 按"题型 × 正误"分层，得到 N_A、N_B。
- **M_B**：N_B 中答对且有完整非空 boxed 的回答，用种子 seed+3 无放回随机抽 100 条（不足 100 条就全用）。
- 所有向量只用 A 半计算；所有指标只在 B 半上计算。

### D2. 向量（全部在钩子位置，全部来自 A 半）

- **d 与 ŝ**：d = mean_{N_A} m − mean_{S_A} m；ŝ = −d/‖d‖（指向 sink）；注入幅度 a = α·‖d‖（`sink_direction`）。这个 d 与当前一轮的 d_run 不完全相同，需报告 cos(d, d_run)。
- **τ**：用种子 seed+4 从 N_A 抽 300 条回答，每条最多取 200 个生成 token（`subsample_token_indices`，用一个种子为 seed+5 的 rng 依次调用）。teacher forcing 取 token 激活 h_t，计算 z_t = h_t·ŝ，τ = z_t 的第 75 百分位（`tau_from_projections`）。同时记录 S_A token 的 z 分布。
- **v_T（题型匹配目标）**，见 `type_matched_targets`：
  - 目标集依次尝试三级："同题型、答对、level ≥ 4" → "level ≥ 3" → "任意 level"，第一个满足 ≥ 20 条的那一级胜出；都不够就用全部答对的非 sink 回答。
  - sink 端用同题型的 sink 回答，不足 10 条就用全部 S_A。
  - v_T = ‖d‖·单位化(目标均值 − sink 均值)。每个题型实际用了哪一级回退，都要记录。
  - v_T 用到了正确性标签，写作时称为"标签指导的方向"。
- **局部 chart 表（C3）**，见 `chart_vectors`：
  - token 级 map（block 14，在 MATH 训练集前 16 个生成 token 上拟合）的每个区域 s 有局部基 U_s（D×8）。
  - û_s = 单位化(U_s U_sᵀ d)；投影为零的区域不干预。因为 d 固定，û_s 只取决于区域，可以事先算好查表。
  - token 的区域分配沿用 token 级 map 的规则：默认最近中心（`nearest_centroid`）；如果那张 map 按 GMM 后验分配，就换成它。

### D3. 干预（施加在所有生成位置）

| 名称 | 规则 | 借鉴 |
|---|---|---|
| NONE | 不变 | — |
| C0 | h ← h + a·d̂ | CAA / ActAdd（当前方案，作参照） |
| C1 | z = h·ŝ；若 z > τ，则 h ← h − (z − τ)·ŝ | CAST 条件式干预 + directional ablation |
| C2 | h ← h + α·v_{T(q)} | 题型匹配目标（"去哪里"） |
| C3 | h ← h + a·û_{s(h)} | 区域局部子空间（"空间对不对"） |

- C1、C3 的判断（z 和 s(h)）一律用干预前的 h。
- numpy 参考实现：`apply_add` / `apply_clamp` / `apply_chart`。
- 钩子里用的 torch 版本：`make_torch_transform`。

### D4. 对照

- **单位向量只生成一次，三族共用**：
  - 各向同性 r_iso^1..5：`iso_controls(D)`，种子 seed+1；
  - 流形上 r_man^1..5：`manifold_controls(非 sink 状态中心)`，种子 seed+2。从 response 级 map 第 14 层的非 sink 状态中心里取 5 个随机的不同对，方向为 ±(c_i − c_j)，再单位化。
- **CTRL_ADD**（C0、C2 共用）：h ← h + a·r。
- **CTRL_CLAMP**（C1 的对照）：沿 r 做同样的截断，τ_r 取同一批 N_A token 在 r 上投影的第 75 百分位。
- **CTRL_PROJ**（C3 的对照）：û_s(r) = 单位化(U_s U_sᵀ r)，h ← h + a·û_{s(h)}(r)。
- **条件命名**：`{族}_{iso|man}_{k}`，例如 `CTRL_ADD_man_1`（见 `control_condition_names`）。决策代码依赖这个命名。
- **条件总数**：1（NONE）+ 4（候选）+ 30（对照）= 35。

### D5. 上下文与指标

**Sink 题**（S_B；r 为历史贪心回答）

- **截断点 c**：`cut_token_index`，依次尝试"第一个重复句的句首 → 最接近一半的句首 → token 数的一半"，并记录用了哪条规则。
- **M_ans(q, 条件)** = Σ_j log p(y_j | prompt ⊕ r[:c] ⊕ tok(FORCE) ⊕ y_{<j})，其中 y = tok(标准答案 + "}")。每个条件一次前向。
- **M_loop(q, 条件)** = 原回答中截断点之后各 token 的平均 NLL，在完整回答的一次前向里取。续写不足 20 个 token 时记为缺失。
- 每道题每个条件共两次前向。

**正常题**（M_B；r 为答对且 boxed 的回答）

- 在完整回答的一次前向里同时取两个量：
  - **M_col_ans**：最后一个 `\boxed{` 之后、到与之匹配的 `}`（含）为止，这段字符所覆盖的 token（与区间有交集即算）的 log 概率之和。这里用模型自己的答案写法，避免和标准答案的格式差异。
  - **M_col_nll**：全部回答 token 的平均 NLL（次要指标）。
- 每道题每个条件一次前向。

**长表**：`step2_screen_long.parquet`，每个（题，条件）一行，列为 `question_id, set, condition, family, m_ans, m_loop, m_col_ans, m_col_nll`。`set` 取 `sink` 或 `normal`；不适用的格子填 NaN。

### D6. 通过规则与决策（用 `step2_decision`，不要手工判断）

对候选 C 及其对照族 N(C)，Δ 一律指"该条件 − NONE"。只用在 NONE、C 和全部对照上都有效的题，以保证配对、样本数相同。

- **P1**：mean Δ_ans(C) 的 bootstrap 95% 区间下界 > 0。
- **P2**：mean Δ_ans(C) 至少超过 ⌈0.95·|N(C)|⌉ 个对照的 mean Δ_ans。对照有 10 个时，即须全部超过。
- **P3**：mean Δ_col_ans(C) 不低于对照中最差的那个（即不是 11 个里伤害最大的），并且 ≥ −0.10 nats。
- **P4**（只报告，不参与判定）：mean Δ_loop(C) > 0。
- **通过** = P1 ∧ P2 ∧ P3。

**决策**

1. **`c0_generation_beats_random` 的定义**：在当前一轮的**完整**结果中，用冻结评分器统计，HSS 组"答对且 boxed"的目标题数严格多于随机组。
2. 如果 C0 通过筛选，而 `c0_generation_beats_random` 为假，就判定筛选与生成结果不一致：不跑 3A，改跑 3B。
3. 否则，在通过的新候选（C1、C2、C3）中，取 mean Δ_ans 最大者为最优。其余通过的候选，如果与最优者的逐题差值的 bootstrap 95% 区间含 0，就视为并列。在并列者中按 C1 > C3 > C2 的顺序选出一个，进入 3A；匹配对照取同族的 `man_1`。
4. 没有新候选通过：进入 3B。

**关于假阳性**：在可交换的零假设下，一个无效候选偶然满足 P2 的概率约为 1/11。再加上 P1、P3 会更低，但三个新候选合起来，仍可能有一成左右的假阳性。所以 3A 在测试集上的生成是确认，不是走形式。

### D7. 必须报告的诊断（不影响决策）

- **幅度**：‖d‖；a 与钩子处 token 范数中位数之比；cos(d, d_run)。
- **C1 的作用范围**：在 S_B token 和 M_B token 上被截断的比例，以及平均改动幅度 ‖Δh‖；各截断对照同样报告。
- **"空间"诊断**：
  - ‖U_s U_sᵀ d‖/‖d‖ 在 S_B token 所到区域上的分布（`chart_vectors` 返回的 ratio）；
  - d 的范数平方落在 N_A token 激活前 8、64、512 个主成分里的比例；
  - S_B token 到最近 token 级中心的距离，超过训练分布第 99 百分位的比例（覆盖不足率）。
- **C2 细节**：每个题型的 v_T 回退级别；C2 按题型拆开的结果。
- **汇总表**：每个条件一行，即 `decision_table_markdown` 的输出，外加每个对照各自的均值。
- **图**：每个候选的 Δ_ans 与其对照分布画在一起（点图）。

### D8. 输出

- `step2_vectors.npz`：d、ŝ、τ、各 v_T、对照向量及其 τ_r、û_s 表、所有种子；
- `step2_screen_long.parquet`；
- `step2_decision.json`：`step2_decision` 的原样输出；
- `step2_diagnostics.json`。

## E. 第 3 步：唯一一次生成

**时间门槛**：预计完成时间加 1 小时，必须早于冻结时间（2026-09-26 01:59 UTC）。赶不上就整体顺延到讨论期，不做缩水版。

### E1. 3A（有新候选通过时）

- **题目**：与当前一轮相同的 55 道目标题和 100 道正常题（测试集）。
- **组别**：
  - 选中的候选 C*，向量用第 2 步 A 半算出的那些；
  - 匹配对照：`step2_decision.json` 里的 `matched_control_for_3A`；
  - zero 组：从当前一轮 zero 组抽 10 题，用同一管线重跑。逐字一致就复用当前一轮的 zero，否则整组重跑。
- **设置**与当前一轮完全相同。
- **主终点**：目标题中"答对且完整非空 boxed"的题数。分别做 C* 对 zero、C* 对对照的配对比较（`paired_binary_summary`，McNemar 精确检验）。
- **次终点**：
  - 目标题：boxed 率、顶到长度上限的次数、平均 token 数；
  - 正常题：相对 zero 的净答对变化和 boxed 变化；
  - 对新输出做第 1 步的重新编码，报告离开率。
- **正文门槛**：只有 C* 对对照的主终点 p < 0.05，才在正文写一句；否则只进附录。

### E2. 3B（没有新候选通过，或筛选被判定与生成不一致时）

- **触发**：
  - 用第 1 步存下的 zero 组前缀均值、冻结的 §5.2 前缀 map、HSS-NB 打分器，以及 Table 2 的冻结阈值，逐个句子边界打分。
  - 边界记为 b_0（开头）、b_1..b_n（各句末尾）。f(q) = 第一个分数达到阈值的非末尾边界。
  - 没有触发的题，保持 zero 组的输出不变。
- **对每道触发的题**，三组各采样 k = 4 次（T = 0.7，top_p = 1，回答总长上限 2048，其余设置不变）。前缀用 `retry_prefix_boundaries`，采样种子用 `sample_seed`：
  - **R-HSS**：保留前 f−1 句（f = 1 时即从头开始）；
  - **R-RAND**：保留随机的前 u 句，u 从 {0, …, n−1} 中均匀抽取，按题固定；
  - **R-START**：从头开始。
- **每组最终答案**：4 个样本 boxed 答案的多数（`majority_vote`，规范化用冻结评分器的函数；并列时取最早的样本；都没有 boxed 则记为无答案）。
- **主终点**：触发的目标题中，最终答案"答对且 boxed"的题数。分别做 R-HSS 对 R-RAND、R-HSS 对 R-START 的 McNemar 精确检验。
- **次终点**：
  - 每题生成的 token 数（算力）；
  - 4 个样本中至少一个答对的比例；
  - 被误报的正常题相对 zero 的净变化；
  - 整条"监控 → R-HSS"管线在全部 55 道目标题上"答对且 boxed"的题数，对比 zero。
- **正文门槛**：只有 R-HSS 对 R-RAND 的主终点 p < 0.05，才在 §5.2 写一句；否则只进附录。

## H. 给执行 agent 的实现提示

- **钩子**：沿用当前 block 14 的钩子，只替换变换函数。用 `make_torch_transform(kind, ...)` 生成 f，在钩子里执行 `hs[gen_mask] = f(hs[gen_mask])`，其中 gen_mask 只在生成位置为真。
- **似然计算**：teacher forcing 一次完整前向就能拿到所有位置的 log 概率，不要用带 KV cache 的逐步解码。
- **等价性检查**：在 GPU 上先跑 `check_torch_equivalence()`，确认 torch 版本和 numpy 参考实现的最大误差 < 1e-4。
- **随机性**：全部来自 `PARAMS["seed"]` 派生的种子，并把实际用到的种子写进输出。
- **决策**：生成 `step2_screen_long.parquet` 之后，直接调用 `step2_decision(screen, c0_generation_beats_random=...)`，把返回的字典原样存成 JSON，再用 `decision_table_markdown` 生成汇总表。
- **自检**：`python hss_followup_tools.py` 会跑全部自检（文本工具、干预、划分、题型目标、统计、各种决策分支）。改动代码后必须重新跑一遍。
