## 2. 算子：保留局部部分，削弱补空间

令s=q(h)是原activation的区域，a_s为当前运行真实使用的重构anchor（不预设它与GMM中心相同），U_s为正交rank8基，P_s=U_s U_s^T。

R_s(h)=a_s+P_s(h-a_s)

u=P_s(h-a_s)，v=(I-P_s)(h-a_s)

h_alpha=(1-alpha)h+alpha R_s(h)=a_s+u+(1-alpha)v=h-alpha v。

因此：
- alpha=1移除相对于当前局部仿射子空间的补空间部分。
- alpha=0.1削弱该部分10%，不是把activation范数减少10%。
- 这不是在局部8维内添加一个正确性方向，也不是donor坐标交换。
- 每个修改位置保留自己的region与8维坐标，其他token、层及上下文保留；不是整段推理8维压缩。
- “去噪”“回到正确计算状态”仅为待检验解释；投影到PCA仿射子空间不保证处于高密度区域，也不保证重新assignment不变。
- map与PCA可以无标签拟合，但选择alpha/位置使用了验证正确性，整条控制方案不能称为完全没有标签参与。

## 3. P0：保护256题确认试验

不得改变正在运行的模型、tokenizer、分区、anchor、basis、layer hook、alpha、窗口、题目IDs、随机条件、采样设置、最大长度或判分器。

不得在同一A100上并行启动第二个LLM runner来占用吞吐；空闲显存不等于GPU计算闲置。CPU可以准备后续manifest、统计脚本、缓存和图表模板。

不查看部分测试正确率来选方法、选子组或决定是否停止。运维可以检查完成数、失败、NaN、磁盘与延迟。

六个条件均从相同的自然16-token前缀出发。baseline必须经过与干预条件等价的重启/重算路径，identity检查复用已有审计证据。历史patch后需重算受影响的后续激活和KV，不能只编辑离线tensor。

已有统计协议优先。不把本文件写作时补充的分析伪称试验开始前预注册；若未定义分析，须在不看测试outcome条件下时间戳锁定，并说明锁定时间。

主终点：local8相对baseline的配对正确率差、错转对、对转错、95%问题级配对区间。

关键辅助：local8对shared8、各随机控制的直接差及区间。需要总体多比较结论时报告辅助比较的Holm调整；不要把pointwise区间称为同时覆盖区间。

若三个随机条件只是同一随机机制的重复，先在题内平均，题为统计单位；若它们是不同机制，分别报告。绝不使用best-of-3随机答案，也不选最差随机条件当主对照。

基础输出：各方法正确率、修复/损伤、有效答案率、空/格式/截断比例、生成长度、壁钟成本、干预覆盖率。实际网络/运行失败与模型答错分开记录；不静默剔除未完成配对。

四个条件：
1. baseline；
2. 原已冻结local8规则：同模型、hook、t=16、W=4、alpha=1；
3. same-anchor shared8；

每题若在t=16以前已经结束，按冻结策略“不干预，保持baseline”，保留在总样本与覆盖率中；不得为了达到窗口强制继续。

此组只验证原规则的冻结跨数据表现，不能作为新消融winner的确认。wrong-local优势若出现仍须结合实际改变量解释，单独不足以证明唯一因果语义。

## 5. 原验证集上的10项解释性消融

从原64题中，通过固定hash顺序选32题，不按baseline正确性、修复结果或早期测试信息选题。baseline和原local8结果仅在完整配置、prefix、seed和实现hash一致时复用；否则按预算补跑。

全部结果标为探索性。除表中列出的因素外，继承原冻结配置；这些变体绝不回填256题主试验。

| ID | 唯一改动或诊断变体 | 目的 | 优先级 |
|---|---|---|---|
| D01 | same-anchor wrong-local8，固定无标签置换 | 检查正确region–basis配对是否重要 | P1 |
| D02 | same-anchor shared64 | 区分保留原输出与改善正确率；增加rank是否更好 | P1 |
| D03 | local16 | 判断rank8附近的压缩敏感性 | P1 |
| D04 | alpha=-0.3，放大补空间；与已有+0.3对比 | 方向符号诊断，不预设对称或单调 | P2 |
| D05 | W=1，其他不变 | 当前最后位置是否已足够 | P1 |
| D06 | W=16，其他不变 | 窗口扩大是否增加损伤或收益 | P1 |
| D07 | t=8，W=4 | 干预更早的时机敏感性 | P2 |
| D08 | t=32，W=4 | 干预更晚的时机敏感性 | P2 |
| D09 | 完整投影后恢复该位置原L2范数 | 径向变化的敏感性；是新变体非主方法修复 | P2 |
| D10 | 同窗口各token统一减去补空间残差均值 | 区分逐token重投影与窗口共同偏移 | P2 |

D02/D03只有与当前实际anchor、训练集、粒度相容的basis可用时运行；不得把同名的旧GMM中心版与当前经验中心版混用。不存在则标missing_asset，不临时重训分区或偷换basis。

D09：r=R_s(h)，若||r||足够大，h'=||h|| r/||r||；近零异常按预定义规则记录并回退到不干预。恢复norm不保证保持原region或子空间中的相同仿射性质。

D10：先从未修改窗口提取v_j=h_j-R_{s_j}(h_j)，令v_bar=mean_j(v_j)，一次性修改h'_j=h_j-v_bar。此操作保留该层窗口内token间差值，移除共同偏移；它与逐token删除v_j的总能量不同，需报告，不能声称匹配扰动预算。它不需要新建mean-map。

t=8/32与W变化均使用自然前缀，不拼接标准解答、不根据最终答案选择边界。W≤t；早停样本按“不干预”规则保留。

## 7. 原确认结果的解释矩阵

- local8优于baseline，且对shared/随机有清楚增量：支持本模型/数据/解码条件下的几何引导局部重投影控制；仍不证明每个cluster是推理变量。
- local8优于baseline，shared或随机效果相近：收益可能不是HSS特有。非显著差不等于证明等效；如实报告差值与区间。
- 原确认区间跨零：验证增益未确认或精度不足；保留既有功能保真结果，不在同256题上继续挑alpha。
- 主试验负向而新冻结GSM8K正向：报告跨任务异质性，不能只留下正向数据集。
- 只有验证变体胜出：是下一轮候选，不替换当前正式结论。

每题只能使用冻结策略的一次输出进行主准确率评分，不查看正确答案在baseline/steered之间挑最佳。不把随机三次best-of的计算预算与单次local相混淆。
