旧验证的4个评分冲突为：math_2696（相同多项式因式分解，未boxed被取成7）、math_412（相同6x−5，末句x<5被取成5）、math_643（双方算28，后续现实鞋码讨论使提取到46）、math_81（同为50，boxed中的x=50与裸50匹配不一致）。修复和损伤各2次，在所核查翻转中净抵消。因此不能把旧验证收益全部归因于评分错误。保留9次最终答案修复、2次损伤，但其中一些正确终值仍伴随不充分或错误推导。

## 证据支持的解释

1. **样本角色不同。** 旧64题用于在C1 alpha=.1/.3/1与C2 .1/.3五个候选中选择方法；各候选原自动净增为+5、0、+7、0、0。被选中的+7是同一小批题上的最好值，通常会比冻结后的新题表现更乐观。这不是测试泄漏，而是正确区分发现与确认的必要性。
2. **操作能修也能损，平衡尚不稳定。** 旧64题每题占1.56个百分点；256题每题占0.39个百分点。小集几题差异会大幅影响百分比。确认中17修复对16损伤说明改变行为的能力仍在，而可重复的净收益没有建立。
3. **评分也含误差。** 新256题的8个冲突偏向自动修复，旧64题的4个冲突在已审查翻转中净抵消；需要所有条件的独立版本化全量评分检查。复算同一评分器仅证明可重复，不能证明其提取语义正确。
4. **几何解释仍是假设。** 当前投影保留局部8维，删除补空间；它不知某道题的补空间是干扰还是有用信息。两批题可能落在不同的这种组合上，但当前数据未证明具体题型/区域差异是原因。不能在确认题上事后挑有利子组并当确认收益。

谨慎结论：早期正信号值得做确认，但没有获得稳定净纠错的确认；不能说方法从未修对题，也不能说小样本已证明普遍提升。先前较强的功能保真/KL证据仍有其限定含义，不能替代自由答题正确率证据。
