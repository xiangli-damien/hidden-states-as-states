# 状态路由：首轮执行结果

日期：2026-09-20。主数据：Qwen2-7B-Instruct × MATH 5,000，2,378 正确、2,622 错误。报告入口：`http://127.0.0.1:8774/report/index.html`。

## 结论

**跨层路径有高阶依赖，但尚未得到优于简单基线的无正确性标签失败检测器。** 正确／错误的部分条件路由差异存在；它们对聚类粒度、初始化和控制变量敏感。现在不能称为一条已确证、可跨任务使用的“走向失败的路径”。

### 1. 路径结构不是只由一阶边表决定

从当前簇预测下一层时，再知道前一层的簇可降低折外 log loss。交换同一中间簇处的整条后缀，严格保留每一折内的所有相邻层边计数，得到对照：

| 方法 | 二阶预测原始增益，nats | 保留一阶边的打乱均值 | 超出对照的增益 |
|---|---:|---:|---:|
| 原 GMM | 0.4709 | 0.2346 | 0.2363 |
| 与 MFA 相同 K 的 GMM | 0.1280 | -0.0057 | 0.1338 |
| MFA | 0.1434 | -0.0071 | 0.1505 |

199 次打乱均小于观察值，每种方法 Monte Carlo p=0.005；三项 Bonferroni 校正后 p=0.015。这个分辨率不能被写成更小的 p。

原 GMM 在 null 中也出现 0.2346 的增益，反映计数稀疏和不同平滑方式的影响，因此不能把 0.4709 全部叫作“记忆”。额外增益支持当前簇没有概括全部跨层依赖，但未控制全部连续几何／题目特征，也不是时间上的推理记忆证明。

### 2. 正确／错误条件路由有残余，但局部位置不稳定

控制起点簇、题型、难度、回答长度四分位、prompt 长度三分位和结束原因后：

- 主 GMM：3/27 对相邻层在探索性 FDR 检查中显著；共同支持覆盖平均仅 15.6%。
- 主 MFA：7/27 对显著；覆盖平均 52.1%。
- 同 K GMM：3/27 对显著；覆盖平均 49.7%。
- MFA 两个独立种子各有 7 对显著，但三个种子共同出现的只有 **25→26 层**。这不等于同一条边或同一种语义已经复现。

分组要求每类至少两题。共同支持之外不能外推；分箱也无法完全排除连续混杂。GMM 簇较多，强控制后尤其缺乏可比较样本。

加入平均 token 熵二分位后，MFA 与同 K GMM 没有相邻层通过该控制家族的 FDR；它们的共同支持也降至约34%。**这不能证明熵解释了一切，只能说明尚未排除不确定性解释。**

几何控制改用题型、难度、长度、当前 RMS 与 Mahalanobis 距离后，MFA 仍有2对显著，GMM与同K GMM各1对；覆盖不同，不能简单把显著层数量相减当作解释比例。

### 3. 类别占用保留对照没有支持“额外强化的失败分流”

在正确性和 nuisance 组内分别打乱各层，保留每层类别占用，破坏真实跨层配对。打乱会改变分支数量和有限样本偏差，因此原图与每张打乱图都减去各自精确的条件标签置换期望：

| 方法 | 真实校正 JS，bits | 占用保留 null 均值 | p，真实更大 |
|---|---:|---:|---:|
| 原 GMM | 0.01228 | 0.01746 | 0.954 |
| 同 K GMM | 0.00683 | 0.02686 | 1.000 |
| MFA | 0.01144 | 0.02567 | 1.000 |

真实分流没有超过这个对照，甚至更小。这与相邻层在真实路径中携带较冗余的类别信息相符。它不否认前面的高阶结构，也不能证明路由没有任何预测信息；两种 null 检验的问题不同。

### 4. 无标签风险评分仍落后于简单基线

所有分数方向预先固定为“越大越容易失败”，没有根据评价标签反转方向。

| 分数 | 失败 AUROC | 95% 条件 bootstrap 区间 | 同 nuisance 分层内 AUROC |
|---|---:|---|---:|
| 原 GMM context | 0.566 | 0.550–0.581 | 0.537 |
| 同 K GMM context | 0.416 | 0.401–0.432 | 0.458 |
| MFA context | 0.437 | 0.422–0.454 | 0.475 |
| MFA node rarity | 0.627 | 0.610–0.643 | 0.545 |
| MFA soft route JS | 0.471 | 0.455–0.488 | 0.478 |
| 回答长度 | 0.775 | 0.762–0.786 | 0.583 |
| 完整回答平均 token 熵 | 0.689 | 0.675–0.703 | 0.629 |

同 K 后 GMM 的分数方向接近 MFA，说明先前方法差异明显受聚类粒度影响；该对照也重新估计了中心，不能把全部变化严格归因于 K 或 covariance 单独一个因素。

分层内 AUROC 只比较同组的正负样本，并按样本对数量加权；与总体 AUROC 不是相同估计目标。400次bootstrap条件于已保存地图与分数，不包含重新拟合不确定性。

### 5. 不是简单的后验边界抖动，也未证明超出连续几何

- 训练样本上 GMM 后验最大值<0.9 的逐层比例平均仅约0.0021%；MFA为0。
- 改成最近中心，GMM约12.7%、MFA约20.5%的逐层归属变化。
- 主MFA与两个种子的逐层ARI中位数约0.61；同K GMM与MFA约0.478。

因此后验很尖锐不等于解稳定。协方差会影响分区和路径；当前结果尚不足以建立独立的离散状态机。
