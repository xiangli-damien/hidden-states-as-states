# 三个真实例子：逐 token 激活与均值向量

用户要求直观看量级和方向。读取既有 OpenAct Qwen2-7B-Instruct × MATH 的原 block14、原始3584维激活；没有新推理、聚类或标签拟合。

## 取样和来源

在读向量数值前，固定取上一轮96题列表中最先出现的三道MATH题：math_3992、math_2916、math_2668。对应290、253、786个生成token，共1329个；包含EOS。不是代表性抽样，也不是正误对照。完整回答均值逐题与旧HSS缓存完全一致；从per-token重新平均与存储均值在浮点误差范围一致。

所有前16均值、完整回答均值、单token来自同一次原生全序列teacher-forced前向。没有将重新prefill捕获与原生full-sequence激活混合；本图不宣称逐值等同上一轮重构干预的重新捕获。

这些夹角与norm直接在3584维计算，不是二维投影的估计。交互图每个面板仅画一对向量，以均值为横轴，把token的正交剩余作为纵轴，严格保留这对向量的长度和夹角。两个面板使用不同平面，不能比较面板之间或切换token之前之后的绝对朝向。

## 解释边界

- 先平均向量再取norm，不同于先取norm再平均。均值更短来自朝向不完全一致时的部分抵消；不意味着token普遍互相反向。这三题前16token两两余弦的平均值分别为.469、.447、.442。
- 前16均值长度约为前16平均token长度的69–71%，这不是保留了69–71%的信息，更不是正确率。
- 不同窗口均值有31–35°差异，直观说明前缀mean与完整回答mean不是同一个点。它不能单独证明旧地图分簇塌缩或干预失败的因果原因。
- 累计均值在最后等于完整均值是数学定义，不是模型主动朝目标收敛的证据。
- 仅展示三题、一个中间层；不推广到所有模型、层或正确/错误样本。
