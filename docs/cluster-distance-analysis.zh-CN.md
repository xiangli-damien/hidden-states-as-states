# 距中心的距离：典型性、偏离与回答行为

## 复现

先生成 cluster explorer，再运行（读取已保存的模型，不重新聚类）：

```bash
python scripts/analyze_cluster_distances.py \
  --report /lambda/nfs/dami/hss/qwen-math-cluster-structure-20260919 \
  --states /home/ubuntu/hss-cache/data/473f2199a8742bdf18996361/layer_28.npy \
  --rows /home/ubuntu/hss-cache/data/473f2199a8742bdf18996361/rows.parquet
python scripts/enrich_cluster_structure.py \
  --report /lambda/nfs/dami/hss/qwen-math-cluster-structure-20260919 --render-only
```

本地复制模型时可用 `--fits-root inputs/fits`，其下按方法名存放 `fit.json`
和 `model.npz`。脚本检查原始矩阵哈希、样本 ID，并验证模型重现全部原有标签。
`distance.html` 是交互页面；`distances.json` 保存每题距离、分位、交叉拟合预测、
折号和来源哈希；`distance_members.parquet` 便于后续分析。`--render-only`
只重新渲染页面。页面支持 `?method=mfa_r8_k21&cluster=2&metric=euclidean&sample=math_2734`。

## 距离定义

- 中心为保存模型的 component mean，不是重新计算的 hard-assignment 均值。
  两者距离也保存在结果中；原 cluster explorer 的“距经验中心”排序采用后者。
- 欧氏距离使用原始特征单位；Mahalanobis 使用已拟合协方差，GMM 为对角，
  MFA 为 `WWᵀ + diag(ψ)`。没有改变输入、标签或模型。
- MFA 的沿因子/正交因子距离是 W 列空间的正交投影及残余的欧氏长度，
  平方和为欧氏距离平方。与可旋转的单个 W 列区分。
- 另存 `z_MAP = (I + WᵀΨ⁻¹W)⁻¹ WᵀΨ⁻¹(h-μ)` 的 norm 和 Ψ 加权重构残差；
  两者平方和等于 Mahalanobis 距离平方，与上述正交分解含义不同。
- 簇内百分位用平均秩处理并列值，只是本批相对排名，不是尾概率或异常 p 值。

## 正确性检查的界限

主检验是每簇距离五分位与正确率/长度的描述曲线。全部簇曲线合并各自簇内排名，
防止把大尺度簇误当成更异常。95% Wilson 区间只描述比例，不覆盖聚类选择。

辅助模型对正确性做固定 5 折交叉拟合，控制题型、难度、簇编号、log 长度和截断；
另加 hidden mean norm，然后分别加欧氏、Mahalanobis 或 MFA 两个正交距离。
分类特征 OneHot，连续特征用训练折拟合的 5-knot 三次样条，逻辑回归 C=1；
不调参、不筛特征。400 次配对分层 bootstrap 只重采样固定 OOF 预测。
聚类已在全部 5,000 条上拟合，故这是固定几何下的探索性关联，不能称为完整
管线的独立测试；区间也不覆盖重新拟合/选模的不确定性或多项探索比较。

## 2026-09-19：目前观察

- MFA K21/rank8 全部样本，固定“越近越正确”的簇内百分位 AUROC：欧氏 0.512，
  Mahalanobis 0.501；距离不是通用正确性指标。
- Cluster 2，欧氏最近/最远五分位各 52 条，正确 1/52 与 9/52，分别 1.9% /17.3%；
  长度中位数 1,210 / 873.5。沿因子距离对应为 1/52 与 10/52。Mahalanobis
  最近/最远为 1/52 与 3/52，趋势弱得多。因子方向与长度可能共同参与，不能归因。
- MFA 控制模型 AUROC 0.8234，加入欧氏距离 0.8246，增益约 0.0012
  （条件配对区间约 [0.0001, 0.0022]）；Mahalanobis 无正增益。
  效应很小，尚不能声称额外机制或泛化。
- KMeans K2 加欧氏距离约 +0.0050，而 KMeans K21 约零，说明距离的增益还依赖
  分簇粒度。不同方法/不同 K 的条件基线不同，不能据此排名聚类质量。

## 三个原文案例（人工阅读，示例选择不代表频率）

选取规则：Cluster 2 中欧氏最近的错误样本、最远的正确样本、最远的错误样本。
这些是有意选择的极端案例，不是盲评，也不是匹配题目对照。

1. **math_2734**，L4 中级代数，1,489 tokens，错误。欧氏百分位 0.2%，
   Mahalanobis 13.7%。多项式因式分解问题中，回答把未知商 `q(x)` 错当作
   常数匹配系数，然后反复说要纠正/重新考虑，重复同一推导，最终以问题复杂、
   建议查资料结束，没有给出全部 b。正确设置应是一次商 `x+a`，由
   `a+b=2`、`b(a+1)=2` 可得 b=1 或 2。这个案例支持“中心附近可存在
   反复解释但未完成求解”的具体观察，不能推广成整个簇的定义。
2. **math_2235**，L4 中级代数，631 tokens，正确。欧氏/沿因子均为约 99.0%，
   Mahalanobis 65.6%。几何数列问题中，从两项差消元得到 r=4、a1=3，
   最终明确算出和 1,023。偏离中心主要沿模型允许的因子方向，整体回答仍很常规。
3. **math_2171**，L5 中级代数，1,300 tokens，错误。欧氏 99.8%，
   Mahalanobis 30.2%。不等式问题中主动使用 AM-GM 并给出数值结论，但初始
   分式约简、约束变形和最后代入均有错误。说明远离中心也可以是另一种失败模式：
   表面完成推导，而非拒绝完成求解。

这些例子说明“中心距离 + 方向 + 原文”比单个距离标量更可解释。当前向量是整段
生成均值，不能定位何时开始重复或出错；时序判断需要逐 token 表征和文本对齐。
