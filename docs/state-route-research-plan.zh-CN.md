# 状态路由、几何波动与无正确性标签拟合：研究方案

日期：2026-09-20。状态：**方案与小规模探索性检查已完成；正式验证、控制实验及新聚类尚未运行。**

## 1. 要回答的三个问题

1. 在当前 cosine + Hungarian、eta=0.6 的关联规则下，正确与错误回答是否具有不同的逐层状态占用和条件转移？
2. 差异是否超过初始化波动、边界切分、簇内协方差、题型／长度等因素所能解释的范围？尤其：转移是否提供了单层状态没有提供的信息？
3. 不使用正确性标签拟合分数、挑选层、调整方向或选择阈值，能否得到可迁移的失败风险排序？

“不同路径”“有预测价值”“导致失败”是三个不同结论，需要逐级验证。本研究不预设多跳、罕见路径、大距离或停留都是错误。

### 无标签的边界

本方案默认最严格解释：正确／错误标签只进入最终评估和事后描述，不进入聚类、K/rank 选择、matching、分数拟合、组合权重、阈值和风险方向选择。自动判题、judge、伪正确性标签同样算标签。

允许自监督目标，例如从当前表示预测下一层表示／状态；训练目标不是回答的正确性。允许在无标签验证集上按预测下一层的对数似然、校准、稳定性选择模型。

评估阶段按正确性分组计算转移表、置换检验、置信区间是可以的；这些表不能随后作为“无标签分类器”的参数。任何由这些结果启发的新分数都必须标为探索性，并在另一个冻结的确认实验上验证。

**识别限制：**单独的无标签几何分布不能一般性地告诉我们哪一组叫“错误”；把正确和错误语义交换，不会改变几何分布。无标签方法首先是异常／典型性／一致性评分器。它能否成为失败检测器是待检验结论，不承诺校准后的正确率。

### 2.3 层深度和生成时间不能混用

回答均值的第 1 层到第 28 层路径，是一个完整回答的**跨深度几何摘要**。它不是解题步骤的时间序列；不能从中声称某个推理步骤是首次出错的位置。

真正的提前预警另外使用：prompt-last、前 16/64/128 个生成 token 的均值，以及在线可确定的句子结束边界。每个表示单独训练无标签地图或明确标为跨表示迁移；不能假定完整回答均值模型自然适配 prompt／prefix。

采集采用 teacher-forced causal forward，可以从已保存状态提取前缀；但必须校验 token 对齐、因果 mask、末层 pre/post、只使用该前缀之前的 token。先前 replay 检查不替代新前缀提取的契约测试。

在线特征不能使用最终总长度、完成比例、未来句子边界或最终答案。@50% 等完成比例只能在事后画图评估。已提前结束的短回答单独记覆盖率，不补出未来 token。

## 3. 第一阶段：观察当前地图中的结构路由

冻结模型和 matching 后，每个节点定义为 `(layer, local_cluster)`，全局 ID 只作为跨层几何延续的注释。

### A. 状态占用

估计 P(Z_l=a | Y)，画按类别人数归一化的占用热图。报告正确率和错误率基线、每个节点样本数、区间。回答“是否经过不同区域”。

### B. 同一起点的下一步去向

比较 P(Z_(l+1)=b | Z_l=a, Y, C)，其中 C 是预先固定的 nuisance 分层。

展示每条边的条件概率差、两个方向的比例、支持样本数、区间。汇总时使用正确／错误组共同的起点权重，避免某组更多地进入起点 A，就被误认为 A 的路由不同。

主要全局检验采用每层加权条件 Jensen–Shannon 差异，先做全图检验，再定位层和边。仅绘制 fit 集中支持数 >=30 的主边，稀疏边汇总为 other；阈值不参考正确性。个别边还须展示评估集中的两组支持数，不把缺失／零计数解释为确定禁止通行。

### C. 不同深度是否出现新的分歧

画从浅到深的累计路由分数和增量；最后一层另列 pre/post。先在完整回答上称为“与最终错误相关的深度位置”，不称为“错误发生层”。

### D. 分支、汇合和高阶路径

记录两步／三步 motif、多个来路汇入同一目的状态时的来源比例。Motif 候选由无标签 fit 集支持数定义，不按错误富集筛选；确认集统一评估并做多重比较校正。

深度图是有向无环图。不同深度重复一个 global ID 不自动等于动力系统中的真正回返或吸收态。图中所谓“停留”仅指继承的几何 ID。

### E. 标签使用与不确定性

- 标签用于事后分组和零假设置换，不反馈进 detector 参数。
- 按题／题目组 bootstrap，不能把一题的 28 条边当成 28 个独立样本。
- 多层／多边检验使用整体置换 max-stat 或 FDR，主检验与探索性边分别标记。
- 关联图要显示全量样本与控制后的图，不能只显示显著边；被过滤的流量必须注明。

## 4. 第二阶段：转移究竟是什么——最重要的对照

| 对照 | 保留什么／改变什么 | 可回答的问题 |
|---|---|---|
| 各层独立重命名 | 只置换 layer-local ID；保留样本划分 | 条件转移分数必须不变；否则是实现错误 |
| 初始化重复 | 固定 K/rank，独立重拟合 | 层间变化是否超过聚类解的波动 |
| 拟合样本 bootstrap | 重拟合地图并在固定评估题上预测 | 图的路径和效应是否依赖少量题 |
| 相同 K 的 GMM/MFA | 每层都固定为当前 MFA 的 K_l | 方法差异是否主要来自 GMM 更多簇 |
| 同 K 的 MFA rank4/8/16 | 固定 K，改变簇内相关结构容量 | 路由是否对 covariance 建模高度敏感 |
| posterior / nearest | 保留同一拟合模型，改变硬分配规则 | “路径”是否主要由协方差形状／混合权重造成 |
| soft / hard | 保留后验而非只取 argmax | 是否只是簇边界附近的抖动 |
| norm / 范数 / 长度控制 | 聚类输入仍为原始状态，仅评估时分层 | 是否只是尺度、回答长度或难度代理 |
| 层内连续几何 | 分析 Mahalanobis 距离、后验 margin、残差方向 | 离散边是否提供了连续几何之外的解释 |
| 末层 pre/post | 保留兩套已有提取 | 是否由最后 RMSNorm 几何变换主导 |

### 四类零假设要分开

1. **没有超出起点的正确性路由差异。** 在当前起点簇和 nuisance 分层内打乱 Y，计算条件转移差异的零分布。仅用于评估。
2. **类别差异只来自每层占用。** 在 `(Y, C)` 组内分别打乱各层的样本对应，保留每层正确／错误占用，破坏同一道题的跨层连接。这是事后解释性零模型，不用于训练 detector。它可检验完整路径是否超出各层直方图，但不会保留总体原始转移表。
3. **差异只需一阶边，不需要更长路径。** 使用无标签的一阶、分层转移模型生成路径，检查未参与拟合的路径 motif 和二阶模型的预测收益。对类别高阶检验，可在同一中间节点和 `(Y,C)` 组内交换路径后缀，以保留类别边计数、破坏更长记忆。
4. **硬分配主要反映 Gaussian 边界。** 用拟合 GMM/MFA 的分量做参数化模拟并重新分配，估计边界混淆和期望跳簇；再比较 soft 分数及高置信样本的结果。独立按层采样会破坏真实跨层耦合，因此这种模拟只能检验指定的协方差／分配零模型，不能证明所有变化都是“噪声”。

### nuisance 清单

- MATH：题型、level、prompt 长度；回答后的分析还加回答长度、截断／finish reason。
- 几何：RMS、末层 massive 坐标能量占比、到中心的标准化距离、后验 margin。
- 输出置信度：对应时点可用的 token entropy／logprob；缺失时明确标记，不悄悄补成已存在。
- 在线评分只使用已知的 prompt 信息和当前前缀长度。人工难度标签用于研究控制，不能成为部署必需输入。

先用固定分箱／分层置换，再在需要时用 cross-fitting 的条件检验作为敏感性分析。输出一个“新增变量后效应保留多少”的表。不能凭未显著结果断言效应为零，也不能凭控制后仍显著就断言因果。

**协方差解释可能仍有价值。** 如果路径差异完全由簇内方向、范数和边界解释，应表述为连续几何信号的离散摘要；不能据此宣称模型存在独立的离散状态机。

## 5. 第三阶段：严格无正确性标签的风险评分

所有层的转移矩阵各自估计，不把层深度假定为平稳、可交换的时间。K_l 可变化。不创建按 Y 区分的 Markov 模型。

### 5.1 基础模型与评分

无标签 fit 集估计 pi_l(a)=P(Z_l=a) 和 T_l(a,b)=P(Z_(l+1)=b | Z_l=a)。

1. **单层占用基线**：S_node = mean_l[-log pi_l(z_l)]；末层单独做基线。
2. **条件转移意外程度**：S_edge = mean_l[-log T_l(z_l,z_(l+1))]。
3. **去掉目的状态罕见度后的路线分数**：S_context = mean_l[-log(T_l(z_l,z_(l+1))/pi_(l+1)(z_(l+1)))]。它避免将“目的簇稀少”全部归为特殊路由，但仍是一个统计分解，不保证正确性 nuisance 已被控制。
4. **软路由不一致**：从 r_l 和无标签 T_l 预测下一层 q_(l+1)=r_l T_l，与观测后验 r_(l+1) 比较 JS 距离。r_l 是混合模型后验，T_l 可由后验外积的平均构造；该外积是近似，不等于观测到了真实软转移。主结果保留硬计数以供核验。
5. **连续更新预测残差**：无标签拟合低秩 ridge，预测 h_(l+1) 或 delta h_l；对未见题计算残差，用 fit/calibration 集中的残差协方差计量。层与表示单独拟合，超参只按无标签验证似然／误差选。它检验离散路由究竟是否比平滑连续动力学更有用。

固定主分数为 S_context；其他分数预先登记为对照，不根据上述探索 AUROC改成其相反数或重新选主分数。若未来决定研究另一方向，必须冻结新协议并在新的确认集上测试。

### 5.2 稀疏性与公平比较

主简单基线采用 Laplace alpha=1。GMM 的 K 大，逐格加 1 的总先验强度也大，因此另做与 K 无关总强度的收缩：

T_l(a,b) = (N_l(a,b) + kappa*pi_(l+1)(b))/(N_l(a)+kappa)。

kappa 候选 {1,10,100}，只按无标签 validation 的 next-state log loss 选择。罕见起点回退到该层边际，不让未观察边产生无限分数。二阶模型仅在无标签验证集上有稳定预测收益才加入；总收益必须扣除额外自由度／复杂度。

不把不同 K 的原始负对数似然直接横向排名。用同 K 对照，以及同方法内冻结的无标签校准分位数。Mixture 的高密度不等于真实性；几何异常可能只是罕见但正确的解法。

### 5.3 从分数到拒答／告警

纯无标签版本能用无标签 calibration 集分位数选择“预计标记 10% 样本”的阈值。若使用 split-conformal 异常 p 值，保证也针对同分布、可交换的整体样本尾部；**这不是正确回答上的 10% FAR**。

要把 P(alert | correct) 校准到 10%，需要知道哪些 calibration 样本正确；这是标签校准版本，必须单列，不能混入严格无标签结果。

多前缀在线检查需在 calibration 的整条轨迹上校准最大统计量或另行设定序贯规则，不能在每个前缀各用 90% 分位数然后声称整题误报只有 10%。

失败风险方向在读评价标签之前冻结。若 AUROC<0.5，原样报告，不能自动用 1-AUROC 美化性能。错误可能是常见、稳定、流畅的模式，尤其当前 Qwen MATH 错误占52.4%，不能假设错误就是少数异常。

## 6. 评估协议与数据泄漏边界

### 6.1 已有全量地图：探索轨

重用已保存模型、matching、标签和原文。研究图结构、生成假设、做便宜的计数比较。转移计数 cross-fit 不能消除地图全量拟合的 transductive 性质。

### 6.2 独立拟合：验证轨

沿用40/60主分割的比例习惯，但不按正确性分层：按 group_id 确定性分组，必要时只按题型／subject 分层。40% development 内再划分 fit 与无标签 calibration，所有同题／重复题／多前缀在同一组。

- K/rank 搜索仅使用 fit 数据；预先规定有限候选，不能直接把全量地图选择当成独立选择。
- 数据量改变会影响 ICL 的参数惩罚和 K/rank，必须记录，不强迫得到原来的 rank16。
- 同 K 对照可固定当前探索发现的 K_l，作为明确的设计参数；不声称该 K_l 是在确认集之外从未选择过。
- 不额外 normalization；任何分数中的 Mahalanobis 计量、残差协方差校准应明确与改变聚类输入相区分。
- 固定 split、模型、matching、分数、方向和阈值后保存哈希，再运行 evaluator。
- 新种子和 bootstrap 在同一固定测试题上比较，避免把不同测试集的波动混成拟合波动。

已有 MATH 数据已被反复研究。重新随机切它，不会使它变成从未触碰的确认数据；正式论文须披露。MMLU 可检验任务转移，但部分 MMLU 在早前研究中已被分析，不能一概称为盲测。最强确认需使用冻结后独立保留的新题集／未分析部分，届时另定范围，不在此方案中启动新采集。

### 6.3 主要指标

- 失败 AUROC、失败 AUPRC（标出失败率基线）、risk–coverage 曲线及固定覆盖率的剩余错误率。
- 预先选定分数之间的配对 bootstrap 差值；不能只给单个 AUROC 区间。
- 与长度、范数、entropy/logprob、末层几何和单层占用比较。不同可用信息／生成成本分开比较。
- 稳定性：效应方向、路径分数排序、边差异能否跨种子／子集／方法复现，而非只看中心相似。
- 若要声称“路由比状态占用提供额外信息”，必须通过保留类别占用的零模型，并在冻结确认集上比较 node-only 与 route-aware 分数；一张不同颜色的 Sankey 图不够。
- 合并多个分数时只允许预先固定权重或无标签估计；不得用正确性 AUROC 训练 stacking。任何监督增益分析只能作为另列的诊断，不充当主 detector。

### 6.4 在线扩展

主时点：prompt-last，以及生成 16/64/128 tokens 后；短回答报告适用样本覆盖。随后增加在线句子边界。

报告每时点的 AUROC/AUPRC、提前量、错误检出率和正确回答误报率，后两者仅用评估标签计算。完整回答均值结果不填进 prompt 或 prefix 栏位。

没有步骤级标注时，不能验证首次推理错误的定位；只能观察最终失败的前兆。如需要首次错误定位，另用带步骤标注的数据做评价，步骤标签仍不得参与无标签方法拟合。

## 7. 实验矩阵与执行顺序

| 优先级 | 内容 | 是否新拟合 | 输出／决策 |
|---|---|---|---|
| P0，本次已做 | 当前 GMM/MFA 无标签计数分数、ID置换不变性 | 仅小型转移计数 | 原始分数、探索 AUROC、限制说明 |
| P1 | 冻结 matching 的占用／条件转移／路径图；nuisance 和占用保留 null | 否 | 是否存在可复现的条件路由差异 |
| P2 | soft/nearest、现有种子、pre/post、同 K/rank 控制 | 部分新增 | 区分切分／协方差／初始化因素 |
| P3 | 仅 fit 集建图和无标签评分；独立校准／冻结评估 | 是 | 判断能否称为风险检测器 |
| P4 | Qwen MMLU、Llama MATH 方法复现与迁移 | 按需要 | 任务／模型泛化，ID不跨模型直接等同 |
| P5 | prompt/prefix、后续因果干预 | 按需要 | 真实提前预警和行为效应 |

P1 不因某些图显著就跳过 P2。P3 的主比较最多 GMM/MFA 两类，不扩展到几十个聚类器。先完成 native-K 与 matched-K 两条清楚的对照，再考虑更复杂模型。rank 更高或新的大规模 K 网格不属于当前已启动任务。

现有均值缓存约为 5000×29×3584×4 字节，约2.08 GB，可做快速分析；不反复加载数 TB 原始 token 激活。Prefix 特征确实需要读取相应 token 存储，必须顺序按 shard 提取并缓存，先小样本计时再估算全量。

新增 GPU 拟合前先测两层（中层、末层）时间和峰值显存，再给全程预算；不能用计数脚本耗时推算重拟合。继续保留正在运行的 OpenAct MMLU，不改变采集参数、不重启旧的数周 MFA 队列。

## 9. 建议的软件拆分

以下是后续实现设计，不是假装这些模块已经存在：

- `route/schema.py`：对齐 sample_id、group_id、layer、time、视图；显式标签隔离。
- `route/counts.py`：无标签边际、一阶／二阶转移、稀疏收缩；输入签名不含 y。
- `route/geometry.py`：GMM/MFA 后验、margin、Mahalanobis／因子残差，避免构造所有3584×3584逆矩阵。
- `route/scores.py`：冻结的 node/edge/context/soft/update 分数，记录方向和版本。
- `route/nulls.py`：占用／边结构／初始化零模型，明确哪些仅用于有标签评估。
- `route/evaluate.py`：唯一允许读取正确性标签的评分评价入口；不回写 detector 参数。
- `route/report.py`：仅读取结果表；改配色／关联显示不触发重新拟合。

存储分为不可变 `models/`、`matching/`、`features/`、`scores/` 和 `evaluation/`；每级记录上游哈希。Changing matching 不重新拟合聚类；对于完整分层转移分数，纯 ID 重命名甚至无需重新计算统计。

必要验证：ID置换不变性；组间无泄漏；soft概率行和；无标签阶段无法接收 y；修改未来token不影响当前prefix分数；完整层覆盖；所有正式模型满足收敛契约；评分脚本复跑一致。

## 10. 什么结果分别意味着什么

- **只在节点占用有差异**：不同题／难度落在不同几何区域，暂时没有额外路由证据。
- **路由差异存在，但在长度／协方差／margin控制后消失**：路由是这些连续量的可视化摘要。
- **换 K、rank、seed 就改变方向**：离散化依赖较强，不能稳定解释为失败路径。
- **条件路由在确认集和方法控制中成立，但异常评分无效**：存在行为相关的结构，尚不能无标签判断哪条路会错。
- **冻结的无标签路线分数优于单层／长度等基线，并迁移**：可主张一种无需正确性标签拟合的失败风险评分方法；不能直接声称概率校准或因果机制。
- **在真正前缀上有稳定收益**：才可以讨论提前预警。
- **几何约束干预改变最终行为**：进一步支持参与计算的解释；需等范数随机方向、同簇方向、流畅性／输出熵等控制。此阶段不在当前方案中自动启动。

## 11. 文献位置与创新边界

不能直接宣称“状态轨迹几乎无人研究”。以下工作与本问题相邻，但监督条件和分析单位不同：

- 用户提供的 *Hidden States as States*，第3–4节定义状态图，第5节与附录A.5按标签计数预测。本文方案检验的是超出节点占用的路由信息，以及严格无正确性标签拟合。
- [INSIDE / EigenScore，ICLR 2024](https://proceedings.iclr.cc/paper_files/paper/2024/hash/0d1986a61e30e5fa408c81216a616e20-Abstract-Conference.html)：利用多回答表示的协方差谱度量一致性，不等同于单次回答的跨层状态路由；多采样成本需单列。
- [MIND，2024](https://arxiv.org/html/2403.06448v2)：使用自动生成的真假训练数据并训练 MLP。“无人工标注”不等于本方案的“无正确性标签拟合”。
- [Where Does Reasoning Break?，2026 预印本](https://arxiv.org/abs/2605.13772)：已研究 hidden-state transport 的步骤级错误检测；其摘要明确采用 label-conditioned teacher 和蒸馏 student，不能视为严格无标签先例，也不能忽略它后再声称轨迹创新。
- [Hidden Markov Anomaly Detection，ICML 2015](https://proceedings.mlr.press/v37/goernitz15.html)：结构化序列的异常检测已有成熟研究。借鉴依赖结构建模，不直接移植“异常等于错误”的假设。
- [Do Deep Generative Models Know What They Don't Know?，ICLR 2019](https://arxiv.org/abs/1810.09136)：提醒似然高低不能一般性地代表语义可靠性；不能把低密度自动叫作失败。

值得尝试的贡献是：**在原始 GMM/MFA 状态地图上，用编号不变的条件路由统计、严格的协方差／离散化零模型和无标签校准，检验“结构路由是否确实提供额外的可迁移失败信号”。** 这目前是研究目标，不是已发现的新机制。
