# 同题多次生成：没有证据支持早期 token-mean 的额外预测收益

## 已完成的实验与范围

Qwen2-7B-Instruct，MATH224题，每题4次固定seed随机生成，共896条；训练96题、调参32题、校准32题、测试64题，按问题隔离。主视图是block28的最终RMSNorm前状态、生成第16个token。所有896条在16/64两个边界均有效。全部回答398条正确，9条到达2048-token上限；测试256条中110正确、146错误，5条截断。

这是历史上研究过的MATH问题上的新随机回答。不是全新问题确认；也不是无监督分类或因果steering。基线包含prompt-last、current-token、题型/难度、prompt长度、prompt/current/mean16的norm、当前熵与margin。新增mean16向量，另设duplicate-current对照。只在训练题拟合标准化和权重；32道tuning题选择C。全部30个候选收敛，迭代28–187次；10个表示条件均由tuning选择C=.001。训练/预测内部计时5.09秒，不含前置raw数据加载。

## 1. 主结果：题内没有可靠增益

64道测试题中，28题四条回答有对有错，23题全错、13题全对。题内AUROC只在28道混合题上可估计，每题等权；其余36题仍保留在覆盖和跨题指标中。

| 末层第16个token的读出 | 题内宏AUROC | 95%问题bootstrap区间 |
|---|---:|---|
| 基线B | 0.5402 | [0.4048, 0.6726] |
| B + mean16 | 0.4807 | [0.3526, 0.6131] |
| B + duplicate-current | 0.5521 | [0.4151, 0.6875] |

预定主比较mean16−B：**−0.0595，区间[−0.1549, +0.0357]**。mean16−duplicate-current：−0.0714，[−0.1845,+0.0298]。没有额外收益证据，也不能把负点估计直接称为显著损害。

辅助结果同样不能确立增益：block14/p16的mean16−B为+0.0179[−0.0417,+0.0863]；block28/p64为+0.0357[−0.0565,+0.1280]；p64全前缀mean为+0.0298[−0.0595,+0.1399]。不能从辅助视图挑选更好的一项替代主结果。

主视图跨题AUROC是B=0.7314、B+mean16=0.7281。跨题分数明显高于题内点估计，说明不能把跨题可预测性直接解释为读出了同题某一次解答的特有成败信息。仍不能因此证明所有信号都只是难度，或证明hidden state里完全没有相关信息；本研究只检验固定小样本、有限L2读出及两个早期位置。

## 2. 两次检查的监测没有显示mean改善

只在生成16/64token时检查。独立32道calibration题中只有35条正确回答；三种方法的校准FAR均为3/35=8.57%，满足预定不超过10%的严格阈值规则。没有在测试集重新调阈值。

| 方法 | 测试误报 | 检出的错误回答 | 假设停止可节约的观察token比例 |
|---|---:|---:|---:|
| B | 3/110 = 2.73% | 30/146 = 20.55% | 17.48% |
| B + mean16 | 3/110 = 2.73% | 25/146 = 17.12% | 14.71% |
| B + duplicate-current | 3/110 = 2.73% | 32/146 = 21.92% | 18.31% |

本批恰好具有相同的测试FAR；不能保证未来数据也相同。FAR的95%题级区间为[0,7.56%]；错误检测率区间分别约[8.97%,33.15%]、[6.85%,29.25%]、[11.18%,33.78%]。这些是逐项区间，不是检测率差的显著性检验。

基线能检出一部分错误回答，但mean没有改善该应用的点估计。token节约仅是对完整生成的反事实计数，不代表已节省GPU计算或提高正确率。误报会停止本来正确的回答；校准正确样本仅35条，区间固定本次模型和阈值，没有覆盖重训/校准的不确定性。

## 3. 覆盖、前缀多样性与解释限制

28道混合题中，16-token前缀分别有4题包含2种、13题包含3种、11题包含4种不同序列；到了64token，这28题各有4种不同序列。因而不能把全部无增益简单归因于四次采样都生成了完全相同的前缀。相同前缀仍可能产生不同后续结局，属于本任务真正的不确定性。

16/64覆盖完全相同，报告另保存共同可用轨迹结果。2,000次问题bootstrap、逐项95%区间，未校正多重比较；混合题仅28道，估计仍宽。不追加采样制造更多混合题，不改标签或挑选新的C/层来挽救结果。

**可写入论文的限定结论：**在该模型、问题集和有限读出下，早期生成均值未在prompt、当前状态、置信度与幅度控制之上显示可靠的同题成败区分增益。先前局部低秩重构对输出保真的作用，不能直接推出它能够预测这一次解答是否失败；两条证据回答不同问题。
