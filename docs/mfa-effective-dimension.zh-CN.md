# MFA 的逐层、逐簇有效维度

## 范围

Qwen2-7B-Instruct × MATH5000，使用完成的24小时 MFA 搜索导出：
29 个 HF hidden-state 位置（embedding0、decoder1–27、末层post28）和单独的末层pre28。
当前选定模型全部 rank16，K在各层独立选择。不重新拟合、不改变分配、匹配或输入尺度。
模型曾使用全部5000题，本报告仅作样本内几何描述，不使用正确性标签。

## 主指标

统一使用 participation ratio：

`PR(C) = trace(C)^2 / trace(C^2)`。

- 因子部分：`C = W W^T`，PR不超过rank16。
- 完整模型：`C = W W^T + diag(psi)`，PR可以超过rank16。
- 实际样本：对每个硬分配簇独立中心化，计算完整经验协方差的PR。
  它受 `min(n-1,D)` 限制，有限样本会影响估计。
- 存储对角残余PR、因子方差占比、因子谱、90%/95%因子方差所需方向数。
  因子谱的解释比例以因子方差为分母，不以总方差为分母。
- 另保存因子谱的entropy rank作区分，主图不混用两种定义。

精确、快速的完整模型公式：令 `G=W^T W`，则

```
trace(C) = trace(G) + sum(psi)
trace(C^2) = trace(G^2) + 2 * sum_i psi_i * ||W_i||^2 + sum_i psi_i^2
```

无需构造3584×3584矩阵或进行全维特征分解。小矩阵测试与直接协方差计算逐项核验。
经验PR使用样本Gram矩阵和特征Gram矩阵中较小的一种，不作PCA截断。

## 分布和对照

- 每层提供簇等权中位数、IQR、10/90分位、范围；另按簇内题数提供加权中位数和均值。
  IQR是簇分布，不是置信区间。加权值不是合并全层点云后的有效维度。
- 每簇固定无放回抽100题，20个确定性随机重复。不足100题的簇排除并报告覆盖。
  重复分位数仅是抽样敏感性，不是统计置信区间，不消除所有有限样本偏差。
- 复用既有1042、2042种子的60个模型，对完整模型和因子PR作逐层分布敏感性检查。
  每层rank/K相同，不重新拟合、不匹配簇编号；分布稳定不代表成员划分稳定。
- 末层pre/post分别固定各自簇成员，再对同一批问题计算两种表征的经验PR，
  区分表示变化和重新聚类。两种表示均来自已保存的逐token状态均值，
  不把最终RMSNorm直接作用在平均向量上。

## 审计与复现

读取导出与缓存的sample IDs并验证顺序和5000题完整性。导出局部簇编号与原拟合记录完全一致，
与全局匹配编号也逐行一致。每个表示随机固定256题重算模型预测以核验数据、模型和分配对应。
保存输入数据／模型／分配哈希，结束时确认源文件未变。

```bash
.venv/bin/python scripts/analyze_mfa_dimensions.py --config configs/mfa-effective-dimension.toml
```

输出 `/lambda/nfs/dami/hss/mfa-effective-dimension-20260921`，包含逐层／逐簇CSV、
因子谱、固定样本量重复、种子分布、末层同成员对照、图表、交互页面和清单。
图中末层post单独显示，不把RMSNorm当作新增decoder层。
不同层的簇成员不同，本轮不声称追踪同一个簇的真实维数演化。

## 2026-09-21 实测结果

30个表示位置、223个主模型簇全部完成，rank均为16；最小簇171题，
所以每簇100题对照覆盖全部问题。复用60个额外种子模型，共446个额外簇。
计算用CPU四线程，主分析约26秒，不影响GPU采集。

下表为每层的簇等权中位数；经验IQR是簇间分布，不是置信区间。

| 层 | 因子PR | 完整模型PR | 经验PR | 经验PR的IQR |
|---|---:|---:|---:|---|
| 1 | 8.63 | 18.47 | 17.38 | 15.63–22.39 |
| 7 | 9.02 | 24.75 | 23.66 | 19.55–24.65 |
| 14 | 10.20 | 26.52 | 24.84 | 23.39–27.15 |
| 21 | 8.48 | 21.93 | 20.83 | 19.54–26.04 |
| 27 | 9.05 | 25.26 | 23.96 | 20.80–29.15 |
| 28 pre | 6.20 | 13.53 | 13.00 | 10.40–18.32 |
| 28 post | 5.69 | 11.87 | 11.30 | 10.85–14.24 |

全部主簇的因子PR范围4.20–12.46，完整模型7.23–42.67，经验PR6.95–39.14。
这直接说明相同rank不固定有效维度，且对角残余让完整协方差有效维度可以超过rank。
因子贡献总方差的中位数约61.55%，其余约38.45%来自对角残余。

### 对照

- 每簇100题对照的逐层经验PR中位数，与全部样本趋势的Spearman相关为0.956。
  绝对数值受有限样本影响：第27层降为20.39、末层pre11.31、post10.67，
  但末层较低的现象保留。
- 与主模型逐层完整PR中位数趋势相比，1042／2042两个既有种子的相关为0.804／0.770。
  第27层完整PR中位数分别24.83／24.33；末层pre14.26／14.45、post12.37／12.46。
  这支持粗略形状相近，不证明每个簇的成员或方向稳定。层之间非独立，这里不报告相关p值。
- 固定pre的8个簇成员，post/pre经验PR比值中位数0.902，8个簇全部下降。
  固定post的7个簇成员，比值中位数0.951，6个下降、1个上升（后者约1.384倍）。
  不能概括为RMSNorm必定降低每个簇的有效维度。

### 解释

末层pre已经明显低于前一层，因此低维现象不全部来自最终RMSNorm。
但各层K和成员不同，不能将不同层中位数差异直接解释为某个固定簇被压缩，
也不能把PR当成应当选择的rank：弱方向仍可能影响似然、尾部和分簇。
本次没有做因果干预、正确性预测或全层簇分布匹配。
