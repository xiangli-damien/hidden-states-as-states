# MFA 的逐层、逐簇有效维度

## 范围

Qwen2-7B-Instruct × MATH5000，使用完成的24小时 MFA 搜索导出：
29 个 HF hidden-state 位置（embedding0、decoder1–27、末层post28）和单独的末层pre28。
当前选定模型全部 rank16，K在各层独立选择。不重新拟合、不改变分配、匹配或输入尺度。
模型曾使用全部5000题，本报告仅作样本内几何描述，不使用正确性标签。

## 主指标

统一使用 participation ratio：

`PR(C) = trace(C)^2 / trace(C^2)`。

- 因子部分：`C = W W^T`，PR不超过rank16。
- 完整模型：`C = W W^T + diag(psi)`，PR可以超过rank16。
- 实际样本：对每个硬分配簇独立中心化，计算完整经验协方差的PR。
  它受 `min(n-1,D)` 限制，有限样本会影响估计。
- 存储对角残余PR、因子方差占比、因子谱、90%/95%因子方差所需方向数。
  因子谱的解释比例以因子方差为分母，不以总方差为分母。
- 另保存因子谱的entropy rank作区分，主图不混用两种定义。

精确、快速的完整模型公式：令 `G=W^T W`，则

```
trace(C) = trace(G) + sum(psi)
trace(C^2) = trace(G^2) + 2 * sum_i psi_i * ||W_i||^2 + sum_i psi_i^2
```

无需构造3584×3584矩阵或进行全维特征分解。小矩阵测试与直接协方差计算逐项核验。
经验PR使用样本Gram矩阵和特征Gram矩阵中较小的一种，不作PCA截断。

## 分布和对照

- 每层提供簇等权中位数、IQR、10/90分位、范围；另按簇内题数提供加权中位数和均值。
  IQR是簇分布，不是置信区间。加权值不是合并全层点云后的有效维度。
- 每簇固定无放回抽100题，20个确定性随机重复。不足100题的簇排除并报告覆盖。
  重复分位数仅是抽样敏感性，不是统计置信区间，不消除所有有限样本偏差。
- 复用既有1042、2042种子的60个模型，对完整模型和因子PR作逐层分布敏感性检查。
  每层rank/K相同，不重新拟合、不匹配簇编号；分布稳定不代表成员划分稳定。
- 末层pre/post分别固定各自簇成员，再对同一批问题计算两种表征的经验PR，
  区分表示变化和重新聚类。两种表示均来自已保存的逐token状态均值，
  不把最终RMSNorm直接作用在平均向量上。

## 审计与复现

读取导出与缓存的sample IDs并验证顺序和5000题完整性。导出局部簇编号与原拟合记录完全一致，
与全局匹配编号也逐行一致。每个表示随机固定256题重算模型预测以核验数据、模型和分配对应。
保存输入数据／模型／分配哈希，结束时确认源文件未变。
