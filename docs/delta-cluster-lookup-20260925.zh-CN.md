# 逐层 Δh 簇错误比例：执行定义

用户明确要求每层独立的原始token计数查表，拒绝之前的跨层贝叶斯合并、转移评分和熵融合。本轮只做这一定义。复用已有五个层对 0→1/6→7/13→14/20→21/27→28；不是全28层。GMM与原始向量处理不变，末层是final RMSNorm之前。

## 固定计算

1. 每层各有一个冻结的K32对角GMM，使用已保存的posterior MAP簇编号。不重训、不匹配跨层编号、不normalize。
2. **只用原训练3011道题的全部生成token**。对每层每簇统计来自最终错误回答的token数N_wrong和来自正确回答的N_correct。q=N_wrong/(N_wrong+N_correct)，不平滑、不题目等权、不拟合额外预测器。空训练簇仅回退到训练token总体错误比例，并明确标记。
3. 所有回答逐token查q，保存token×layer的簇编号和错误率。另保存同一层从token1到当前token的简单平均，绝不跨层合并。后者是回答级风险评分，不声称已校准的回答出错概率。
4. 在prefix1/16/32/64/128，对仍在生成的历史测试题分别评估当前token分数和截至当前的平均分数。主时间点64；每个层单独AUROC；2,000次按题分层bootstrap，区间逐项、无多重比较校正。没有根据测试结果翻转分数或选层再宣称确认效果。验证集不训练q，也不调参；其簇计数作为单独描述性表保存。
5. 簇表同时列训练/验证/测试token数、错误比例、贡献问题数。测试比例只描述外部一致性，不回写训练表。按用户要求长回答提供更多token；分数的评估单位仍是问题，不能把同题token当独立测试样本。
6. GMM本身是旧实验对每个训练问题抽4个token拟合的12044训练向量，并非对所有2690319个token重新拟合。**本次错误率统计才使用全部训练token**。K32是旧搜索上界，不称最优。
