# 本轮结果与因果解释（2026-09-18）

全量读取 Qwen2-MATH 5,000、Llama-3.2-MATH 5,000、Llama-3.2-MMLU 14,042 条的末层 pre token 张量，共9,329,204个生成 token；MMLU 复用去重规则，最终分析13,937个唯一 prompt。没有重新生成或改变采集配置。用 FP64 RMS 公式重建的均值与真实 BF16 post 均值，最大相对误差分别为0.0674%、0.0663%、0.1908%。

## Qwen：方向能量与 gamma 的对应关系很关键

固定同一批回答，只改末层算术：

| 条件 | NDR AUROC | CoE-R | CoE-C |
|---|---:|---:|---:|
| Raw pre | .526 | .405 | .498 |
| 只乘 gamma | .720 | .424 | .719 |
| 只做 RMS，gamma=1 | .454 | .431 | .467 |
| 真实 RMS+gamma | .732 | .684 | .724 |

AUROC 来自冻结的60%验证集，保持论文分数方向。只乘 gamma 已恢复大部分 NDR 与 CoE-C 区分力；CoE-R 需要两项组合。gamma 数值随机置换坐标20次，NDR AUROC 范围 .416–.497，中位数 .456。该检查说明特定方向与权重的对应关系重要，不是任意非均匀权重都会产生相同指标。

撤去 gamma 后，正确回答的 RMS-only 均值范数反而更大：41.038 vs 40.181。gamma 对均值方向的有效增益是3.165 vs 3.447，乘上后正误范数差翻转为129.56 vs 137.99。

在 |gamma| 最小的10%坐标上，RMS-only 响应均值的能量比例为正确67.78%、错误62.38%；在 |gamma| 最大的10%坐标上为18.08%、22.40%。这与“正确样本的均值方向更偏向低增益坐标”一致。上述能量比例是逐题归一化后再组平均。

这里不能说模型为正确题调小 gamma：gamma 是固定的。也不能说这些坐标已经被证实存储正确性；它们可能承载题目内容、任务状态或措辞等共同影响正确性的因素。

### 进一步定位：checkpoint 最小 |gamma| 坐标 2570

坐标按 checkpoint 中最小 |gamma| 选取，没有用正确性标签筛选。Qwen 的该坐标为2570（从0开始），gamma=−0.240234，其他坐标 |gamma| 中位数为4.28125。这个假设是在看过总体结果之后提出的，因此仍是探索性检验。

它占 RMS-only 响应均值能量的比例，正确组平均65.29%，错误组59.72%。单坐标运算对照为：

| gamma 条件 | Qwen NDR AUROC，95% CI |
|---|---:|
| 原始 gamma | .732 [.715,.748] |
| 全部 gamma 设成同一个中位数 | .454 [.433,.476] |
| 其他 gamma 均为中位数，只保留2570原始小权重 | .723 [.706,.740] |
| 保留其他 gamma，只把2570绝对值抬到中位数 | .554 [.534,.575] |
| 保留其他 gamma，将2570设为0 | .732 [.715,.748] |

因此，压低这个大能量坐标足以在固定响应上恢复大部分 NDR 区分力；其权重精确为−0.240而不是0并不关键。这解释了“保留 gamma 分布但打乱坐标”为什么会失效，也说明原始大分量可以掩盖剩余部分的范数差异。这里恢复的是一个固定数据上的统计指标，没有重新生成或改变答案标签。

Llama 最小 |gamma| 坐标为1159，执行同样操作，其 MATH NDR 仍都约 .699–.705，MMLU 约 .578–.581；不能将 Qwen 的2570机制推广为所有模型的共同实现。

## 幅度与抵消同时作用，且彼此有关

| 数据 | 单 token post 范数：正确 / 错误 | 跨 token 一致性 C：正确 / 错误 |
|---|---:|---:|
| Qwen MATH | 243.874 / 251.852 | .53073 / .54712 |
| Llama MATH | 104.055 / 103.588 | .49464 / .52117 |

Qwen 正确组每个 token 的范数平均更小，求均值时也抵消更多。对数均值差精确分解为：

```
总差 −0.06217 = token幅度 −0.03184 + 一致性 −0.03034
             = RMS-only均值 +0.02125 + gamma增益 −0.08342
```

各项95% bootstrap区间都不跨0，详见 analysis.json。两行是同一个差异的不同分解，不能把四项相加。gamma 会同时改变 token 长度及其加权后的方向关系，因而“gamma”和“抵消”不是互斥解释；这些数也不是正确率的因果贡献率。

固定每题前16个 token，Qwen 正确/错误均值范数173.89/183.02，差异仍约5%；负范数 AUROC .590 [.570,.609]。因此不能只归因于响应长度不同，但仍未控制难度、题型、具体词汇等因素。

Llama MATH 的单 token 范数在正确组反而略大，均值更小主要体现在更强的跨 token 抵消。Llama MMLU 也是同一方向的弱效应。原始 pre、gamma-only、RMS-only 的 Llama MATH NDR 都约 .70，和 Qwen 的强 gamma 依赖不同。

## 特定弱读出方向 v 目前不能解释 Qwen 的均值差

Qwen 的 gamma 对 v 的增益为4.692，超过各向同性参考4.348；v 不是被 gamma 特别压低的那个方向。每 token 的 v 能量比例正确23.30%、错误24.10%，与“正确组 v 更大所以分母更大”的直觉方向相反。

仅在 RMS 分母中去除 v 的能量贡献、保持分子不变，正确/错误均值范数变成151.28/162.32，差异没有消失。这是分母路径的算术敏感性检查，不是完整模型状态干预；它不排除其他弱读出方向或子空间的作用。

## 我目前的机制判断

**已经有证据的近端机制：**Qwen 正确/错误回答具有不同的方向能量结构；固定 gamma 尤其压低2570这一大能量坐标，改变单 token 幅度和跨 token 一致性，产生更强的 post 均值范数差。单纯原始激活整体变大不够解释它，因为整体缩放会被 RMS 抵消。

**尚未验证的上游解释：**最后几层可能把任务内容、解题阶段或反复出现的回答模式写入不同方向；这些方向恰好具有不同 gamma 增益。正确回答可能在低增益的共同分量中占更多能量，错误回答可能保留更多高增益的共同偏移。当前结果只确认能量结构，不能把这些分量命名为“语义正确”“犹豫”或“重复”。

**同样必须保留的共同原因解释：**难度、题型和输出内容同时影响正确率及方向结构。因此 post 小可能是成功生成的伴随结果，而非导致成功的控制量。全响应均值含有已生成答案的信息，时间上不能自动当成预先自我评估。

下一项真正的行为因果实验应对候选方向/子空间做上游干预，配相同扰动范数的随机方向和匹配输出温度对照，再重新采样测正确率。只把整个 pre 向量乘一个正数，RMS 会基本抵消；只把 post 向量统一缩小主要是在改 logits 温度。当前没有运行新的 decoder 生成干预，采集调度保持原样。
