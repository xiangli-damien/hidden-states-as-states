# 结果：测量效应成立，但单个占比不能完全解释 NDR

## 修正此前的因果措辞

gamma 拉平、恢复 2570 的低权重、抬高该权重这些对照，只证明**对固定回答的表示做这些运算，会改变几何指标**。
它们没有修改模型生成，也没有重新测量回答正确率。因此，不能称为 gamma 导致正确回答的因果链。
“gamma 如何使差异体现在 norm 上”与“模型为何答对”必须分开。

本轮使用原 60% 分区：每个 MATH 3,000 题，MMLU 8,363 题。
该分区已经被前轮使用，所有结果属于探索性后续；CI 是问题级 95% bootstrap，未做多重比较校正。

## 1. Qwen 的 q 不能单独替代 NDR

| 指标 | AUROC | 95% CI |
| --- | ---: | --- |
| 先平均 raw 状态，再算 2570 占比 | 0.6773 | [0.6591, 0.6949] |
| 逐 raw token 算 q，再平均（主检验） | 0.6533 | [0.6340, 0.6725] |
| 2570 总能量 / 全坐标总能量 | 0.6272 | [0.6076, 0.6464] |
| RMS-only 均值向量的占比（前轮定义） | 0.6815 | [0.6637, 0.6989] |
| NDR | 0.7315 | [0.7148, 0.7477] |

主 q 比 NDR 低 0.0782，配对 CI 为 [-0.0969, -0.0586]。
三种 raw q 联合拟合得到 0.7254，看起来接近 NDR；但与 NDR 联合后达到 **0.7667**。
NDR 在三种 q 之上的增益为 **+0.0413 [0.0316, 0.0519]**，因此相近 AUROC 不能说明信息相同。
拟合使用 discovery-only 交叉验证的三次 log/logit 特征及 L2 logistic，具体函数类见协议。

数学原因也明确：post 均值 norm 还依赖 RMS-only 均值的幅度、其余坐标的 gamma 加权方向；
NDR 又包含所有其他层的分子。它不只是 1−q。

## 2. 分子和剩余能量都在变化

Qwen 的逐 token |x_2570| 按回答平均后：正确 **226.00**、错误 **216.79**，
均值差 +9.21，CI [7.11, 11.23]。逐回答坐标 RMS 为 242.60 / 238.81，差的 CI [1.78, 5.75]。
“共同坐标绝对值不变”不符合当前数据。

去掉 2570 后，逐 token 剩余平方能量除以 D−1：正确 **29.410**、错误 **31.680**，
差 −2.270，CI [-2.512, -2.033]；以较小预测正确的 AUROC 为 **0.7058**。
因此剩余 raw 能量的分布也有差异，不能只保留一个占比而丢掉其他量。

当前支持的是两件事同时发生：公共坐标幅度略大，剩余能量较小。
这仍是关联，不能从中区分难度、token 身份、回答长度、词汇组成或“确定性”的作用。

## 3. 中心化能量提供部分统一，但并未完整统一 NDR

mu 仅由 discovery 回答的 raw 均值构造，每道题等权、与正误无关。
统一指标为 mean_t ||x_t−mu||² / D，用其负值预测正确。

| 数据 | 中心化能量 AUROC | NDR AUROC | 中心化能量减 NDR 的配对 CI |
| --- | ---: | ---: | --- |
| Qwen2-7B-Instruct / MATH | 0.7213 | 0.7315 | [-0.0278, 0.0082] |
| Llama-3.2-1B-Instruct / MATH | 0.6424 | 0.7000 | [-0.0817, -0.0334] |
| Llama-3.2-1B-Instruct / MMLU | 0.5444 | 0.5790 | [-0.0496, -0.0177] |

三组均支持正确回答的中心化能量较低，但 Llama 的效果明显弱于 NDR。
Qwen 的两个 AUROC 虽然接近，联合拟合仍为 **0.7539**，比中心化能量单独 +0.0326 [0.0217, 0.0431]，
比 NDR 单独 +0.0224 [0.0144, 0.0303]。故不能将两个量视为同一个量。

把公共均值改为 discovery token 等权后，AUROC 为 0.7171 / 0.6220 / 0.5425，方向未变。
只比较相近回答长度时，主要中心化指标的 AUROC 降为 0.6253 / 0.5794 / 0.5334。
固定前16个 token 后为 0.5917 / 0.6445 / 0.5196。
尤其 Qwen 的全回答效果包含较强的长度/生成过程组成因素，不能把 0.721 直接解释为纯置信度读出。

在题型、难度、prompt 长度、raw 回答均值 RMS、回答长度的联合控制之上，
Qwen 的 q-family 与 NDR 相互补充增益很小：加 NDR 为 +0.00003 [-0.00022, 0.00033]。
这只描述该控制集和函数类下的预测结果；其中含生成后变量，不证明信息等价或因果解释。

## 4. 2570 的定位：早层存在，最终 block 扩大正误差异

按 discovery 全回答 raw token RMS 排名，2570 第1，约为坐标中位数的 **59.9倍**。
在验证集按题目等权统计，它约 **88.2%** 的生成 token 上是绝对值最大的坐标。
这支持它是突出的公共大激活坐标。

它在首个 decoder block 后已明显存在，后几层继续增长，并非最后一层凭空出现。
但回答均值中，最后一个 block 之前的绝对幅度几乎相同（171.71 / 171.13），
之后为 225.60 / 216.17。最后 block 的逐题绝对幅度增量为：

- 回答均值：正确 +53.89、错误 +45.04，增量差 **+8.85 [6.45, 11.03]**。
- 固定 t16：正确 +23.99、错误 +7.71，增量差 **+16.29 [8.93, 23.40]**。
- prompt_last：两组都减小，正确 −15.61、错误 −21.08，减小程度不同。

所以观测定位已指向 terminal block 在不同位置对该坐标的不同更新。
它仍不能区分 attention 与 MLP，也不能证明是“确定时主动写得更多”。
这里的 2570 大部分取负值，上述“增大”均指绝对幅度，不能误读为 signed 值变正。

Llama MATH 的最终层 RMS 最大坐标仍是 1159，但只约为中位数 **4.94倍**，
在末层之前也曾有明显公共分量，最终 block 把它大幅削弱。
因此“Llama 完全没有大坐标”也不严谨；更准确的是最终层的集中程度及 terminal block 更新方式不同。
Llama MMLU 的 discovery 排名第一则是 1021，报告中明确分开。

[See What You Are Told（ICLR 2025）附录 A.1](https://proceedings.iclr.cc/paper_files/paper/2025/file/da8a39bc39ae1c89dd6ebb1e3bcbb3f3-Paper-Conference.pdf)
列出相关模型 Qwen2-VL-7B 的 {458,2570}。它不是本次精确 checkpoint 的证明。
本轮只有 prompt 最后位置和生成位置，没有完整 prompt attention map，故尚不能定性为 attention sink。

## 当前最稳妥的解释与下一步

gamma 的指标作用属于测量几何；正误差异在 gamma 之前已存在，涉及公共坐标幅度、剩余能量和序列方向结构。
“中心化能量较低”是跨模型共有的描述，但既不等于“内容更少/更有结构”，也不完全解释 NDR。

若继续做机制实验，最有针对性的对象是 **Qwen 最后一个 block 对 2570 的 attention / MLP 增量**：
在匹配 token 位置、回答长度及题目难度后分解来源，再做组件或方向干预并测实际输出行为。
在此之前，应停留在上述可检验的几何与更新描述，不把固定表示上的指标变化当作正确性的因果机制。
