# 首批结果：token mean 有用吗？

时间：2026-09-23。模型 Qwen2-7B-Instruct，MATH 5,000；训练/验证/历史测试 3,011/1,003/986。本页比较同一批 986 道测试题，原始 block 输出；第 28 层为 final RMSNorm **之前**。这些历史测试题已经被探索过，结论是探索性结果。

## 1. 生成过程中的窗口均值比单个当前位置更容易读出回答风险

相同 3,584 维表示、相同线性探针族；正则强度在验证集选择，训练集拟合读出标准化。聚类输入没有 normalization。生成时点指已经读入 16/64 个生成 token，均值仅使用该时点最近 16 个 token，没有使用完整回答。

| block / 时点 | last-token AUROC | mean16 AUROC | 配对差值及 95% 区间 |
|---|---:|---:|---|
| 14 / prompt | 0.803 | 0.808 | +0.005 [−0.006, +0.015] |
| 14 / 生成16 | 0.738 | 0.798 | +0.060 [+0.040, +0.082] |
| 14 / 生成64 | 0.742 | 0.765 | +0.023 [−0.001, +0.046] |
| 28 / prompt | 0.812 | 0.819 | +0.008 [−0.005, +0.020] |
| 28 / 生成16 | 0.710 | 0.798 | +0.088 [+0.063, +0.112] |
| 28 / 生成64 | 0.696 | 0.757 | +0.062 [+0.033, +0.090] |

区间为 2,000 次问题级配对 bootstrap，处理预测分数 ties；是 pointwise 区间，未作多重比较校正。

**当前支持的表述：生成阶段的局部均值保留了单个当前位置较难线性读出的、与最终回答成败相关的信息。** 生成前没有观察到稳定的 mean16 优势。它可以是跨 token 聚合降低位置特定噪声，也可以是多个位置携带互补信息；本实验还不能区分这两种解释。

prompt 的 mean16 是 chat 输入尾部，含指令/assistant 模板位置，不能等同题目正文均值。题目正文尾部另有独立 token 表示和干预对照。

## 2. 这不等于发现了独立的“计算 state”

离散 GMM state 加到 nuisance 基线后，增益明显小得多。基线含题型、难度、输入长度、当前表示范数、当前 next-token 熵和 margin；没有最终回答长度。

- block 28 / 生成16：0.7939 → 0.7981，增益 **+0.0043**，区间 **[−0.0046, +0.0138]**。
- block 14 / 生成16：0.7930 → 0.8018，增益 **+0.0088**，区间 **[+0.0018, +0.0160]**；这是未经多重比较校正的探索性小增益。
- 其余本页预定时点的 mean16 state 增量区间都跨零。

线性探针的 mean 优势和离散 state 的受控增益是两个不同问题。不能把第一项的 +0.088 写成 state 超出置信度的增益。GMM 拟合不使用标签，NB/LR 读出使用训练标签；这也不是完全无监督的正误检测。

## 3. 几何审计与必要修正

首批 64 个表示/层/时点组合共 768 个 GMM 候选，全部收敛，ICL 选择已逐项复核；16 个组合的最优 K 位于网格上界 64。不能把它们称作已证明的全局最优簇数。

首轮真实-token codebook 每题只取窗口中 4 个位置，测试却覆盖 16 个位置。固定 chat 模板会让未取样位置存在结构性的覆盖差异。因此，这批结果保留作抽样消融，**尚未用它们作因果结论**。正式干预改用独立命名空间中的全部 16 个训练位置，避免将位置覆盖不足误判为 state 无效。

新版本同时区分：GMM 中心附近的残差 SVD，与按每簇训练样本经验均值中心化的真正 local PCA。两者共享同一 GMM 分配，但不是同一种重构，也都不是 MFA。

## 4. 下一步的判别条件

1. 真实 1/4/16-token 重构是否保留同-prefix KL/NLL及自由生成行为；必须包含等总扰动能量对照。当前尚无这项结果。
2. MATH→GSM8K 冻结迁移。主比较提前固定为 block28 / 生成16 / mean16 对 last-token 的源域冻结 NB；两者使用相同 GSM8K 确认问题。所有其余视图完整报告，不在目标测试集挑最优设置。
3. 冻结 map 只校准读出、目标域重新拟合、训练样本量匹配，分别判断失败来自 label prior、读出还是几何域偏移。

GSM8K 全量 1,319 道正在采集。固定划分为 541 适配、242 验证、536 确认。采集过程会读取标签检查完整性（两道冒烟题也在确认划分内），但不以确认指标选择迁移方法；不宣称确认标签从未被任何运维工具查看。
