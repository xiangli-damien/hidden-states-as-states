# 逐 token／逐句的层间变化：Qwen MATH

## 问题与范围

检验同一个生成 token 的相邻层更新 `h[l,t] - h[l-1,t]` 在整段平均后丢失了什么。
使用已完成的 Qwen2-7B-Instruct MATH 5,000 题，层对为 0→1、6→7、13→14、20→21、27→28。
第 28 层使用 final RMSNorm **之前**的状态。不是相邻 token 差，也不包含跨 RMSNorm 的差。
所有聚类输入都是原始 3,584 维向量，不做 normalization、PCA 或 whitening。

## 三种表示与公平比较

- 整段：所有生成 token 的平均状态与平均更新。
- 逐句：按现有 HSS 标点／换行规则分段，分别计算句内平均状态与平均更新。句子不是人工标注的推理步骤。
- 逐 token：每个生成 token 的状态与更新，完整评分全部 2,690,319 个 token。
- 每种表示均包含原始状态对照；每层各自拟合 GMM，不需要 Hungarian matching。
- 沿用固定的题目级 train/validation/test = 3,011/1,003/986。
- token／句子 GMM 每道训练题恰好抽取 4 个单位；不足 4 个时有放回抽样。长回答不会贡献更多拟合样本。
- 对角 GMM 的 K∈{1,4,8,16,32}，两个种子，训练 ICL 最小的收敛候选胜出；同时保存固定 K=8 对照。K 上界命中明确报告，不视为全局最优。
- ICL 对同一道题的抽样单位使用近似独立假设，是探索性选型；题目级留出表现与配对比较更重要。

## 读出

每题、每层的簇占比归一到总质量 1。转移表也按题目归一，只统计同一道题内相邻的 token／句子。
类别条件的占比和行归一转移概率用训练集正确性标签估计，Laplace α=1。
占比＋转移是组合评分，不冒充独立观测的精确生成概率。
乱序对照在每道题内打乱单位顺序，同一个排列用于全部层，保留占比及单个单位的跨层对应。
乱序同时改变绝对位置结构，因此不能单凭乱序下降宣称发现了推理算法。

比较整段均值、局部占比、局部占比＋转移、乱序，以及同粒度的原始 hidden states。
长度／entropy 基线用训练折外贝叶斯分数进行组合，验证集选择正则；测试集仅做冻结后的评估。
补充句子数量、句长和 token 类型比例控制。以题目为 bootstrap 单位，保持相同比较的重采样索引一致。
不能用整题错误标签认定某个局部 token／句子就是错误步骤；本研究是回答完成后的检测。

## 执行与存储

配置：`configs/local-depth-changes.toml`。

```bash
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 MKL_NUM_THREADS=2 \
  .venv/bin/python -u scripts/run_local_depth_changes.py --stage all
```

CPU 拟合与评分；Safety 继续使用 GPU。读盘两路并发，拟合六个进程、每个两条 BLAS 线程。
SSD 缓存 `/home/ubuntu/hss-local-depth-cache-20260921`；结果 `/lambda/nfs/dami/hss/local-depth-changes-20260921`。
仅当源 float32 数值可以**逐位无损**表示为 bf16 时才用 uint16 存储位模式（约 180 GiB）；不满足即拒绝运行。
解包后再做差分与均值，不降低计算精度。预留至少 64 GiB 加中间特征空间。
读取时校验完成凭据、模型、题目数及 token 数；重新计算的整段均值必须与旧缓存一致。
所有 GMM 候选参数、收敛记录、选型、全序列分配、分类器、逐题分数均保存。
原始 OpenAct 文件不修改。

这是在已反复探索的数据上的新对照实验；不作为独立确认结果，也不能仅据多模态拟合宣称存在离散计算操作。
