# 变化簇的带标签贝叶斯检测

## 问题和预设比较

复用 `change-clusters-20260921` 已冻结的、只在训练题上拟合的对角 GMM。
不重选 K、不改变 hidden state 的缩放，不根据测试正确性挑方向或参数。
目标为回答失败（1），成功（0）。这是带标签分类；新题推断不需要正确答案。

八个贝叶斯读出：

1. 28 层生成均值更新的 categorical NB。
2. 同一 28 层序列的、逐层类别条件 Markov 贝叶斯。
3. 相同五层（1、7、14、21、28）的生成均值更新 NB。
4. 相同五层原始状态 NB，作为表示的公平对照。
5. 五层 prompt-last 更新 NB。
6. 五层 prompt-last 原始状态 NB。
7. 最后一层 pre-RMSNorm 的 token 更新簇计数 multinomial NB。
8. 最后一层 post-RMSNorm 的 token 更新簇计数 multinomial NB。

NB 和 Markov 使用经验类别先验，固定 Laplace α=1。逐层使用独立词表，
不要求跨层簇编号匹配。token 计数来自每题八个随机相邻 token 对；
它们不是连续的八步，因此不对这些离散采样记录拟合时间 Markov。

## 防止过拟合和信息泄漏

保留既有题目级划分：3,011 训练、1,003 验证、986 测试。
GMM 仅见训练题；贝叶斯仅用训练标签；测试标签只在模型和预测分数冻结后评估。
当前数据已反复探索，所以仍是探索性结果，并非独立确认或论文 40/60 严格复现。

长度和平均 token 熵基线：

- 主基线：log1p 长度和熵各用四结点三次样条，逻辑回归 C ∈ {0.01,0.1,1,10}。
- 非线性敏感性基线：固定梯度提升树，100 轮、7 叶、叶最少 30 题、L2=10。
- 对每种贝叶斯分数，都用同一主基线／敏感性基线加上该分数作配对比较。
- 组合模型的训练分数使用训练集内五折 out-of-fold 贝叶斯 log odds；
  验证／测试使用完整训练集拟合的贝叶斯。GMM 词表固定于完整训练集，
  五折只重训带标签读出，不重训 GMM。
- C 只由验证 AUROC 选择；相同效果选择更小 C。HGB 不选参。
- 下游分类器缩放其输入，不对 GMM 的 hidden-state 特征做 normalization。

## 指标与保存

主指标为测试 failure AUROC，报告 AUPRC、Brier、log loss。
每种分数使用验证集作非负斜率的 Platt 校准，不允许通过校准反转分数符号。
10% FAR 阈值只从验证集中正确题的分数求得；报警采用严格 `>`，报告实际测试 FAR／错误召回。

使用 2,000 次按题、正误分层的配对 bootstrap 报告 AUROC 和差值区间。
区间为逐项区间，条件于已拟合的聚类和读出，不含重训不确定性，不校正多重比较。
保存每个贝叶斯模型、五折模型、组合模型候选、输入簇矩阵、逐题分数、
概率校准、阈值、bootstrap 抽样、图表、逐题浏览页面、来源哈希与文件清单。

生成均值和 token 簇计数用于回答结束后的检测。Prompt 单独读出才是生成前预测；
给 prompt 分数加入回答长度和熵，仅是生成后的诊断对照。
预测增益不自动说明推理机制、离散操作或因果关系。

## 实际结果（2026-09-21 UTC）

已完成八种贝叶斯读出及其组合／基线，共 28 种分数。
下表均为相同 986 道测试题；AUROC 正类为错误。

| 方法 | AUROC | 95% CI |
|---|---:|---|
| 28 层变化 NB | 0.7960 | [0.7672, 0.8222] |
| 28 层变化 Markov | 0.7998 | [0.7723, 0.8259] |
| 5 层变化 NB | 0.7990 | [0.7702, 0.8244] |
| 相同 5 层原始状态 NB | 0.7726 | [0.7427, 0.7997] |
| Prompt 5 层变化 NB | 0.7561 | [0.7247, 0.7874] |
| Prompt 5 层状态 NB | 0.7621 | [0.7313, 0.7935] |
| Token 变化计数，pre | 0.6176 | [0.5822, 0.6524] |
| Token 变化计数，post | 0.5993 | [0.5611, 0.6340] |
| 长度＋熵样条基线 | 0.8064 | [0.7790, 0.8315] |
| 长度＋熵树基线 | 0.8010 | [0.7737, 0.8260] |

### 可以支持的判断

- **跨层变化簇可以用于带标签检测。** 28 层 NB 加入样条基线，
  AUROC 从 0.8064 到 0.8234，Δ=0.0169 [0.0064, 0.0278]。
  Markov 加入后达到 0.8283，Δ=0.0219 [0.0106, 0.0334]。
  换梯度提升树基线，两个增益分别为 0.0183 [0.0056, 0.0309]、
  0.0256 [0.0131, 0.0381]。这与此前无标签异常检测不同：这里明确用了正确性标签。
- **尚未证明转移关系优于逐层簇组成。** Markov 比 NB 高 0.0039，
  配对 CI [-0.0068, 0.0148]。不能因其点估计稍高就宣称发现特有的失败路由。
- **更新表示单独检测优于相同五层状态表示**：Δ=0.0264 [0.0118, 0.0415]。
  但补充检查发现二者都加入长度／熵后，更新只高 0.0026 [-0.0029, 0.0080]；
  因此尚不能说更新特征具有原始状态没有的额外信息。
- **八对 token 的变化簇计数较弱**，加入样条基线后的差异分别为
  -0.0004 [-0.0011, 0.0002]、-0.0001 [-0.0003, 0.0002]。
  不能把这个结果外推到完整逐 token 轨迹。
- **单独的 prompt 特征已经可预测约 0.76 AUROC**，但更新没有明确胜过状态。
  这表示部分信号在生成前就可读；不等于模型知道最终正误，也可能是题目难度等因素。

### 阈值与概率

验证集按 FAR ≤10% 校准，测试集：28 层 NB 的 FAR=9.17%、错误召回=42.61%；
Markov 的 FAR=6.77%、错误召回=45.08%。Markov＋样条基线的测试 FAR=10.48%、
错误召回=55.11%；基线自身 FAR=9.17%、召回=51.70%。
这些召回对应各自验证阈值，不是严格相同测试 FAR 下的比较。

原始 NB 严重过度自信：28 层 NB 的 Brier 从 0.2663 经验证集校准降到 0.1844，
log loss 从 3.2472 降到 0.5433。报告中的逐题错误概率使用校准结果；
高概率仍不是“确定错误”，校准也没有独立跨数据集保证。

模型、输入簇矩阵、分数和图表已保存于 Dami 与本地同名目录。
拟合／统计共约 10 秒（不含前期实现、测试、图表和文件审计），无需重新聚类。
补充的“调整后更新 vs 状态／Markov vs NB／28 vs 5 层”在看到初步结果后加入，
单独标为事后探索，不改变已冻结模型、分数或主要比较。
