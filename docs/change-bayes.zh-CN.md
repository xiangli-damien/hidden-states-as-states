# 变化簇的带标签贝叶斯检测

## 问题和预设比较

复用 `change-clusters-20260921` 已冻结的、只在训练题上拟合的对角 GMM。
不重选 K、不改变 hidden state 的缩放，不根据测试正确性挑方向或参数。
目标为回答失败（1），成功（0）。这是带标签分类；新题推断不需要正确答案。

八个贝叶斯读出：

1. 28 层生成均值更新的 categorical NB。
2. 同一 28 层序列的、逐层类别条件 Markov 贝叶斯。
3. 相同五层（1、7、14、21、28）的生成均值更新 NB。
4. 相同五层原始状态 NB，作为表示的公平对照。
5. 五层 prompt-last 更新 NB。
6. 五层 prompt-last 原始状态 NB。
7. 最后一层 pre-RMSNorm 的 token 更新簇计数 multinomial NB。
8. 最后一层 post-RMSNorm 的 token 更新簇计数 multinomial NB。

NB 和 Markov 使用经验类别先验，固定 Laplace α=1。逐层使用独立词表，
不要求跨层簇编号匹配。token 计数来自每题八个随机相邻 token 对；
它们不是连续的八步，因此不对这些离散采样记录拟合时间 Markov。

## 防止过拟合和信息泄漏

保留既有题目级划分：3,011 训练、1,003 验证、986 测试。
GMM 仅见训练题；贝叶斯仅用训练标签；测试标签只在模型和预测分数冻结后评估。
当前数据已反复探索，所以仍是探索性结果，并非独立确认或论文 40/60 严格复现。

长度和平均 token 熵基线：

- 主基线：log1p 长度和熵各用四结点三次样条，逻辑回归 C ∈ {0.01,0.1,1,10}。
- 非线性敏感性基线：固定梯度提升树，100 轮、7 叶、叶最少 30 题、L2=10。
- 对每种贝叶斯分数，都用同一主基线／敏感性基线加上该分数作配对比较。
- 组合模型的训练分数使用训练集内五折 out-of-fold 贝叶斯 log odds；
  验证／测试使用完整训练集拟合的贝叶斯。GMM 词表固定于完整训练集，
  五折只重训带标签读出，不重训 GMM。
- C 只由验证 AUROC 选择；相同效果选择更小 C。HGB 不选参。
- 下游分类器缩放其输入，不对 GMM 的 hidden-state 特征做 normalization。

## 指标与保存

主指标为测试 failure AUROC，报告 AUPRC、Brier、log loss。
每种分数使用验证集作非负斜率的 Platt 校准，不允许通过校准反转分数符号。
10% FAR 阈值只从验证集中正确题的分数求得；报警采用严格 `>`，报告实际测试 FAR／错误召回。

使用 2,000 次按题、正误分层的配对 bootstrap 报告 AUROC 和差值区间。
区间为逐项区间，条件于已拟合的聚类和读出，不含重训不确定性，不校正多重比较。
保存每个贝叶斯模型、五折模型、组合模型候选、输入簇矩阵、逐题分数、
概率校准、阈值、bootstrap 抽样、图表、逐题浏览页面、来源哈希与文件清单。

生成均值和 token 簇计数用于回答结束后的检测。Prompt 单独读出才是生成前预测；
给 prompt 分数加入回答长度和熵，仅是生成后的诊断对照。
预测增益不自动说明推理机制、离散操作或因果关系。
