# 冻结 token-mean 地图的替换结果

2026-09-24。96题（历史MATH32、此前功能GSM64），16条件，共1536条实际前向记录。正式功能阶段329.50秒；队列包含准备、真实smoke、完整执行、两次审计和报告共约9.34分钟。协议见[token-mean替换计划](tokenmean-replacement-20260924.zh-CN.md)。

## 结论

**旧全回答token-mean地图直接用于前16token时，没有复制逐token地图的局部8维优势。** 两种操作须分开：只改均值保留了全部token间残差，扰动很小，但local8没有可靠优于shared8；用均值选出的一个区域直接投影每个token，则保真明显较差。不能把该结果概括成所有token-mean表示无效。

|---|---:|---:|
| 原逐token地图，shared8 | 2.76635 | 4.30242 |
| 原逐token地图，local8 | 1.87366 | 2.89313 |
| 旧mean地图，只改均值，centroid | 0.07084 | 0.12560 |
| 旧mean地图，只改均值，shared8 | 0.04446 | 0.08860 |
| 旧mean地图，只改均值，local8 | 0.04832 | 0.09150 |
| 旧mean地图，只改均值，错基3次平均 | 0.05517 | 0.09565 |
| 旧mean地图，逐token投影，centroid | 9.82262 | 9.14064 |
| 旧mean地图，逐token投影，shared8 | 6.72404 | 8.47411 |
| 旧mean地图，逐token投影，local8 | 7.57374 | 8.95939 |
| 旧mean地图，逐token投影，错基3次平均 | 8.30525 | 8.88809 |

KL为原始下一token分布到干预分布的KL，越低越保真，不是准确率。只改均值依然保留16个token的高维中心化残差，因此不能把.0915与2.8931宣称为同编码预算优势。

## 预定主比较及辅助结果

GSM只改均值local8−shared8：

- KL差 **+.002897，95%区间[-.009726,+.015888]**。
- 完整原模型参考续写NLL差 **+.000479，[-.000126,+.001112]**。
- 没有局部基额外优势证据。与错基的KL差−.004156[-.013302,+.004055]也不确定。
- 相对只改到centroid，local8仍降低KL：−.034101[-.053159,−.018077]，NLL差−.002720[-.003549,−.001921]。这支持连续信息有用，不足以支持区域专属方向胜过共享方向。

旧mean区域逐token local8−原token-map local8：GSM的KL差 **+6.066265，[+5.014654,+7.139244]**，完整参考NLL差+.060105[.049977,.070987]。这是一整套协议的比较：K33/64、分配方式、学习的对象同时不同，不能单独归因于某一个因素。

MATH方向一致，但mean GMM曾用全部5000MATH拟合，MATH结果是transductive描述性检查。GSM64没有用于地图或方向拟合，却已被以前实验查看，本次属于旧题上的新方法比较，不是全新独立确认。所有区间按问题2000次配对bootstrap、逐项95%，不包含重训不确定性，无多比较校正。

## 前缀均值与原地图明显不匹配

冻结地图由完整回答的均值拟合；干预时只允许使用前16token的均值：

- GSM：只占2个簇，**63/64**题进入cluster2，另一题进入cluster16。
- MATH：只占4个簇；前缀均值的区域与原完整回答均值区域一致的只有 **4/32=12.5%**。
- 全部96个前缀均值的模型log-density都低于全回答训练均值的第5百分位。该阈值为描述性分布诊断，不是事后排除或干预gate。

因此，本轮实际检验的是“完整回答mean地图→早期前缀”的迁移。后验最大值很尖锐也不能消除分布偏移。不能由该结果宣称训练在同一早期窗口的mean地图也无效；它尚未拟合或测试。也没有用未来全回答mean做oracle区域选择。
