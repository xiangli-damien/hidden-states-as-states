# 同题多次生成：token mean 是否携带本次解答的成败信息

## 科学问题与范围

现有跨题读出不能充分区分静态题目难度与生成过程信息。本实验在同一prompt下采样4条解答，在相同token位置比较最终成功/失败的轨迹。使用既有线性读出家族检验mean在强控制之上的增量，不新增聚类、SAE/VQ或分类器搜索。

这是Qwen2-7B-Instruct在历史上已研究的MATH问题上的**新随机生成**，不是从未分析过的新问题确认集。继承原来的问题划分，所有本轮拟合都不能访问本轮test标签。它与已完成的局部重构实验是独立应用线，不能合并成已证明的局部方向机制。

## 固定问题与生成预算

共224道题、每题4次独立固定seed采样，合计896条生成：

| 角色 | 问题数 | 轨迹数 | 继承的原划分 |
|---|---:|---:|---|
| 训练读出和特征变换 | 96 | 384 | train |
| 选择既有L2强度 | 32 | 128 | validation |
| 校准报警阈值 | 32 | 128 | validation，独立于调参题 |
| 最终测试 | 64 | 256 | test |

按问题组ID的固定SHA排序选择，不读取旧标签、响应或新结果。调参与校准使用validation池中不重叠的题。分组重复、数量不足、seed碰撞均报错，不补入其他split。所有4条轨迹留在同一角色，不按轨迹随机拆分。保留同题重复生成的相同答案，不因缺少成功/失败混合而追加采样。

模型revision `f2826a00ceef68f0f2b946d945ecc0477ce4450c`。直接复用已审计的MATH prompt和chat-rendered token IDs；真实tokenizer逐题验证，禁止重新措辞或截断。生成固定temperature0.7、top_p0.95、top_k0、repetition_penalty1.0、max_new_tokens2048、bf16/SDPA、batch1、fresh cache，每轨迹独立设置seed。这是随机采样协议，与原greedy采集不同；不直接比较两个协议的准确率来推断进步。EOS与长度上限、生成IDs/原文、解析答案和判分均保存。

## 采集表示，先限定能看到的信息

生成结束后，以保存的prefix做教师强制前向，不能从generate的隐状态拼接。保存同一个真实prompt-last以及生成边界16、64的：

- block14和block28的原始block输出；block28明确是最终RMSNorm前。
- 当前生成token、最后16个生成token的各自向量、mean16和整个已生成prefix的mean。
- 最终RMSNorm后的对应表示另存，用于契约核对；本轮主比较使用pre-RMS，不事后换表示。
- 当前下一token分布的raw entropy与top1-top2 logit margin，以及本次前向的完整下一token log-probability向量，便于独立复算。

只处理已到达且尚未结束的边界：生成长度必须大于边界，前缀不能含EOS。无效边界保留原因，不能借用prompt token补足窗口。每题prompt状态对四条轨迹应完全相同。用于决策的特征只含当前或过去信息，不含最终回答长度、结束原因、最终标签或未来token。长度上限标签保留并报告截断率；不把上限当自然结束。

主视图固定block28/pre-RMS/prefix16。辅助视图是block14/prefix16和block28/prefix64；prefix64额外记录all-prefix mean对照。各边界可用题不同，任何“随时间变化”描述必须补同一可用题集合的对照，不能混合不同覆盖率。

## 有限的读出比较

采用已有的L2 logistic regression，失败标签为1。每个视图只比较：

1. `B = prompt-last + current-token + controls`。
2. `B + mean16`，主候选。
3. `B + duplicate(current-token)`，暴露额外特征块改变有效正则化的对照。
4. 仅prefix64的`B + all-prefix mean`，辅助。

controls所有方法相同：log prompt长度、prompt/current/mean16向量norm、当前raw entropy与margin、原题型与难度。主比较控制mean16的norm，以检验向量方向/内容的增量；不得悄悄删掉强baseline。固定边界使当前生成长度相同；最终长度不进入特征。

连续特征用训练题统计量做逐维标准化，仅用于读出；原始激活和任何已有聚类不变。类别编码仅在训练题拟合。所有变换、权重和预测保存。C仅三值`[0.001, 0.01, 0.1]`，每种表示由独立tuning题的log loss选择；相同候选范围与收敛预算。不使用calibration/test标签选参。最大2,000次，若达到上限，仅允许同初始化继续至4,000次并如实记录；没有收敛候选则失败，不能解释其指标。没有其他分类器或层/rank搜索。

## 主统计：题内区分，而非跨题难度

在每道test题内，将最终成功与失败轨迹的风险分数做AUROC（tie计0.5），然后对题宏平均。只有该视图有有效边界且同时出现两类标签的题参与这一项；必须报告这类题占全部64道的比例、可用轨迹数、全对/全错/过短题数。不能把正确-错误轨迹的所有两两组合当独立问题。

主比较：每题`AUC(B+mean16) − AUC(B)`的宏平均，2,000次问题bootstrap；同时报告对duplicate-current对照的差，不以两者中更有利的一个替代主比较。辅助报告全部有效test轨迹的跨题AUROC、log loss与Brier，区间同样按题重采样。单类或零混合题时输出明确不可估计，不伪造0.5/0结果、不增样本。区间逐项报告，不能外推普适优势或因果含义。

## 相同FAR的有限监测比较

只在预先固定16、64两个位置报警，是两次检查的监测实验，不能称逐token在线检测。

每种方法在calibration的最终正确轨迹上，取两个可用边界的最大风险分数；都不可用记为负无穷。只在这批独立校准题上选严格`score > threshold`规则，使经验FAR不超过10%；tie保守处理。不把两个位置各校准10%再混称response-level10%。该经验阈值不保证真实总体FAR恰好10%，必须给出test实际FAR及题级区间。

报告失败回答检测率、第一次报警位置，以及若在该位置停止可节约的剩余token数。节约量使用已完成响应作反事实计数，不能宣称实际已节省计算或纠正答案；截断回答只能按本次观察的长度估算。测试集不用于重新定阈值。调参、校准、测试角色均隔离。

## 实现检查与执行次序

1. CPU准备224题、896个唯一seed，tokenizer验证、输入与代码SHA冻结。这一步不生成答案。
2. 新命名空间实现生成、教师强制提取、独立判分/算术/ID/覆盖审计。至少小模型检查prompt不随采样改变、prefix因果性、pre/post RMS关系、实际窗口与mean、entropy/margin、恢复不重复写入。
3. 先2道训练题×4次真实smoke并独立审计；通过后才全量。失败保留，不使用test结果修改科学协议。
4. 全量生成与独立审计通过后，再有限读出、独立统计复算、报告、PNG/PDF与逐题原文复查。不得把准备完成等同实验已运行。
