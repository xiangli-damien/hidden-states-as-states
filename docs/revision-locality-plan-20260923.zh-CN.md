# 局部低秩表示：先辨别解释，再扩大方法（2026-09-23）

## 最新优先级

根据用户本轮完整建议，先检验**区域身份是否帮助选择应保留的连续方向**。GMM＋local PCA保留为已知基线；MFA是待比较的候选。此前自动任务的“先做真实MATH纠错”顺序被本计划替代。SAE/VQ、更大分类器、跨层动力学与数学正确率提升暂不扩展。

现有2.899→0.648指特定centroid基线下的下一token KL改善约78%，不是保留78%的模型功能。原0.648来自每簇经验均值的local PCA；固定GMM中心的残差SVD是另一方法，不能混称。

## 第一批：局部方向、几何对照和clean-state消融

### 固定数据、选择与信息边界

- 模型Qwen2-7B-Instruct，原固定revision、bf16、HF SDPA；不采样，只比较真实forward原始logits。
- 复用已审核的完整前缀提取。所有基只由原训练题的全部16个位置拟合；raw activation不normalize。源数组重新核对提取receipt的SHA。
- 不重拟合GMM：原最近中心分区与K=64固定。每个比较中保留同一套中心，避免把anchor变化误当basis优势。
- 原先32验证＋32历史测试的干预题全部排除；重新按题ID固定哈希选32＋32。**这是新的干预题，不是全新确认集**，因为历史MATH测试早被用于其他分析。所有方法共享同题，缺失位置显式排除。
- 主设置：已生成16token、第14个block output、替换实际16位置。辅助：相同prefix的1/4位置、chat尾16位置、题目正文尾16位置、最后第28个block的生成16位置。末层过去位置作用受架构限制，单列解释。
- 范围仍是单层一次patch；保留其余上下文与模型。每个token单独编码，8维意味着**每个位置**8个坐标，不是整段推理8维。

### L1：同中心、不同连续基

令s是原h的最近GMM中心，r=h−μ_s。固定编码器分配，在训练残差的未中心化二阶矩上求SVD：

1. `centroid`：μ_s。
2. `shared_r`：μ_s＋U Uᵀr；训练全部残差共用一个基。
3. `local_r`：μ_s＋U_s U_sᵀr；保留原先每簇残差SVD。
4. `wrong_local_8`：中心仍为μ_s，仅基换成另一簇；3个预定无固定点置换，seed42/137/271全部汇报，不挑最差。
5. 经验中心桥接：原经验center-only、经验local PCA8、在相同经验中心下的shared8。这样才能解释原0.648中的中心与方向两部分。
6. 全局PCA8保留原训练均值，补充其inverse-mean恢复测试。

主比较在运行前固定：**GMM-center local8 − GMM-center shared8**的next-token KL与完整参考NLL，验证／历史测试分别报告。经验中心比较和置换均属次要。三个置换先在每题内平均再bootstrap；另报每个seed，不能把seed×token当独立问题。

预算曲线：local ranks4/8/16/32；shared ranks4/8/16/32/64/128/256/512。同rank比较保持每token连续坐标数相同，但local需K套基。K=64时shared256/512分别与local4/8的存储basis标量数相同，但连续编码更多。两种公平性分别报告，不能宣称所有预算同时相同。编码器中心、额外经验anchor与每位置region ID单列。

### L2：径向和跨token结构对照

针对δ=μ_s−h，分别运行3个固定seed：

- 逐token等能量随机方向：保留旧对照作为桥接。
- 径向匹配随机：保留h·δ和||δ||，随机化h正交补中的方向，因此理想算术下也保留||h+δ||。
- 对整段误差作同一个随机正交变换：实现为保留误差Gram矩阵、随机化行空间取向的Haar薄框架；避免构造3584×3584矩阵。它保留各位置误差内积，不同时保证径向匹配。

所有不变量用合成数据验证；真实运行记录bf16舍入前后逐token能量、径向内积、最终norm、误差Gram以及region重分配。浮点下不声称严格相等；审计实际偏差。有限幅度KL比值不能称作导数或“敏感性倍数”。

### L3：原始激活上的消融

u=U_sU_sᵀ(h−μ_s)，v=(h−μ_s)−u；预定α=.25/.5/1：

- 原始h减去αu。
- 与该操作径向／能量匹配的随机变化，3seed，剂量间共享随机方向。
- 原始h减去αv。
- 沿补空间v方向，匹配移除αu的逐token能量；它是幅度对照，不保证径向匹配。

α=1去补空间等于固定中心local8重构，是可检查的代数联系；去局部部分则保留其他残差，不应与重构混淆。允许“加回有效、从clean移除作用弱”的结果。所有变换重新编码记录留在原region的比例，不凭公式宣称簇内操作。

### 输出与审计

每个条件fresh prefill/cache，只patch一次；实际patch激活与保存的prefix激活逐元素核对。存每个条件的原始next-token logprobs与逐参考token NLL，可独立重算KL、完整NLL、首token/前16token NLL，防止长参考均值稀释短暂影响。报告argmax保持率、几何误差、实际能量、状态保留率；所有条件而非只报主结果。

问题是统计单位；2000次配对bootstrap，pointwise区间，多重比较范围明确。先真实模型1题执行冒烟并完整审计，再运行64题；冒烟题来自已冻结集合，不据其科学结果改方法。来源/源码/decoder/条件/输出SHA入计划，变更时另建目录，旧数据不覆盖。

**实施状态：** 本计划和`configs/revision_locality_20260923.json`是新协议；只有出现各stage的成功标记与审计文件后才能标完成。共享基拟合、真实功能评估、完整审计、报告分开执行。根目录`/lambda/nfs/dami/hss/revision-locality-20260923`。

## 文献与区别

- [Activation patching的方法与解释](https://arxiv.org/html/2404.15255v1)：从受损状态恢复和从clean状态消融检验不同问题，干预分布会影响解释。本计划分别实施，不把一项替代另一项。
- [From Directions to Regions](https://arxiv.org/html/2602.02464v1)：已有MFA区域、局部因子和重构设定。当前HSS的component-specific diagonal EM与论文方法不同；新增主张必须来自更具体的区域—方向功能配对证据。
- [End-to-End Sparse Dictionary Learning](https://arxiv.org/html/2405.12241v2)：已有直接优化输出KL的字典学习。现在不把改成KL训练作为新颖性，也不在这一批更换方法体系。
