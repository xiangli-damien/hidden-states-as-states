# Historical bundle import/export compatibility

This package is retained so existing notebooks continue to import. New reproduction work uses `hss.data`, `hss.experiments`, `hss.results`, `hss.analysis` and `hss.viz`.

See [the architecture](../docs/architecture.md) and [paper artifacts](../docs/paper-artifacts.md) for the supported pipeline, result contracts and CLI. Do not add a second implementation of a new experiment here.
